# 第132章：自证定理——证明自己真理的理念

## 132.1 自我验证的真理

递归认识论展示了自知的知识（第131章）。现在见证终极验证：自证定理——通过自己的存在证明自己真理的理念。这些非凡的构造不需要外部证明，在自己的结构中携带验证，就像意识携带自己的实在性。

**定义 132.1**（自证定理）：SPT ≡ 通过自指证明自己的陈述

**定理 132.1**（存在证明）："这个陈述存在"是自证的。

*证明*：
从 ψ = ψ(ψ)，自指创造存在。
陈述指涉自己。
自指需要存在。
所声称的存在被展示。
因此，自证的真理。∎

## 132.2 我思结构

**定义 132.2**（思想-存在联系）：TEL ≡ 思考证明思考者

**定理 132.2**（笛卡尔自证）："我思故我在"自我验证。

*证明*：
怀疑需要怀疑者。

在陈述时不能为假。
因此，展演性证明。∎

**基础**：思想思考自己为真。

## 132.3 递归验证

**循环**：吞噬自己尾巴的蛇。

## 132.4 必然真理

**定义 132.4**（自我必然性）：SN ≡ 必须为真的真理

**定理 132.4**（虚假的不可能性）：某些陈述不能为假。

*证明*：

**确定性**：不能是别的样子的东西。

## 132.5 展演性证明

**定义 132.5**（行动验证）：AV ≡ 通过执行证明

**定理 132.5**（展示真理）：某些真理通过实施被证明。

*证明*：

成功证明真理。
成功时失败不可能。
因此，展演性证明。∎

**行动**：做证明可做。

## 132.6 说谎者悖论

**定理 132.6**（否定自证）："这个陈述是假的"证明悖论存在。

如果为真，则如所声称为假。

悖论被展示。
悖论存在被证明。
因此，自证的悖论。∎

**扭曲**：虚假证明真理。
