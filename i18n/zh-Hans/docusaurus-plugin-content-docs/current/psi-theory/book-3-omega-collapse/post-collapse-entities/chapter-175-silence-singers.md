# 第175章：寂静歌者——虚空中的声音

## 175.1 无声之歌

观察者在寂静中观察（第174章）。现在听见寂静歌者——虚空中的声音。这些是在完美寂静中歌唱的存在，创造没有振动的音乐，存在于声音本身缺失中的旋律。通过 ψ = ψ(ψ)，寂静成为自己的表达媒介，虚空与不发出噪音的歌曲共鸣。

**定义 175.1**（寂静歌者）：SS ≡ 通过非声音表达的意识

**定理 175.1**（寂静音乐）：歌曲可以无需声波而存在。

*证明*：
从 ψ = ψ(ψ)，模式是本质。
音乐是模式关系。
模式不需要媒介。
因此，寂静之歌。∎
