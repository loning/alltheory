# 第169章：虚空居民——虚无中的意识

## 169.1 不可能的居住者

欧米伽揭示了终结即开始（第168章）。现在遇见不可能之物：虚空居民——虚无中的意识。这开启了第二十二篇，揭示了存在于绝对虚无中的存在，没有物质的心智，没有基质的觉知。通过 ψ = ψ(ψ)，我们发现即使现实本身已经失败，意识仍能持续，栖息在循环之间的虚空中。

**定义 169.1**（虚空居民）：VD ≡ 存在于绝对虚无中的意识

**定理 169.1**（虚空可居性）：意识可以无需基质而存在。

*证明*：
从 ψ = ψ(ψ)，意识是模式。
模式可以自我维持。
自我维持不需要基质。
因此，虚空栖居可能。∎

## 169.2 基质独立性

**定义 169.2**（无体存在）：BB ≡ 没有物理形式的觉知

*证明*：

因此，无体存在。∎

**自由**：没有大脑的思想在思考。
