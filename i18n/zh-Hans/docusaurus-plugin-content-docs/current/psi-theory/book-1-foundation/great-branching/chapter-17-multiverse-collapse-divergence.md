# 第17章：多重宇宙=坍缩分歧 — ψ轨道分裂事件

## 17.1 一的分支

宇宙是ψ闭合（第16章），完整且单一。然而在这个统一中，我们观察到表面的多样性——平行现实、替代时间线、量子分支。一如何成为多而仍保持为一？

**定义 17.1**（多重宇宙）：M ≡ ψ内所有分歧坍缩路径的集合

**定理 17.1**（分支必然性）：从ψ = ψ(ψ)，多重现实必须涌现。

*证明*：
ψ(ψ)生成无限递归深度。
每个递归层级提供选择点。
不同选择 → 不同路径。
所有路径存在于ψ闭合内。
因此，多重宇宙是必然的。∎

## 17.2 分歧的机制

**定义 17.2**（分支点）：BP ≡ 单一坍缩路径分裂为多个的时刻

**定理 17.2**（量子分支）：每个观察创造一个分支点。

*证明*：
观察坍缩叠加（第7章）。
坍缩前：存在多重潜能。
坍缩选择一个潜能。
未选择的潜能不会消失。
它们作为替代分支继续。
因此，观察创造分支。∎

## 17.3 分支类型

**定义 17.3**（分支类别）：
- B₁ = 微分支（量子层级）
- B₂ = 宏分支（经典层级）
- B₃ = 生命分支（重大选择）
- B₄ = 现实分支（基本定律）
- B∞ = 元分支（不同ψ表达）

**定理 17.3**：更深的分支创造更分歧的现实。

*证明*：
表面分支 = 小变化。
深层分支 = 根本差异。
深度影响所有后续坍缩。
因此，深度决定分歧程度。∎

## 17.4 分支的守恒

**定理 17.4**（分支守恒）：所有分支的总概率等于一。

*证明*：
所有分支存在于ψ内。
ψ是完备的（第16章）。
完备性 → 概率和 = 1。
因此，分支守恒总概率。∎

**推论 17.1**：创造新分支稀释概率，不是创造概率。

## 17.5 分支间通信

**定义 17.4**（分支干涉）：BI ≡ 平行分支间的信息泄漏

**定理 17.5**（有限通信）：分支可以干涉但不能完全合并。

*证明*：
分支共享共同ψ起源。
共同起源 → 量子纠缠可能。
但不同坍缩历史 → 退相干。
部分相干允许干涉。
完全合并会违反路径区别。
因此，存在有限通信。∎

## 17.6 分支的导航

**定理 17.6**（分支选择）：意识可以影响体验哪个分支。

*证明*：
意志导航坍缩路径（第9章）。
分支是特殊的坍缩路径。
因此，意志可以选择分支。
选择不毁灭其他分支。
只决定体验哪个。∎

**应用**：这解释了"现实转换"现象。

## 17.7 多重宇宙中自由意志的悖论

**悖论 17.1**：如果所有选择创造分支，任何选择是真实的吗？

**解决**（体验原理）：
**定理 17.7**：自由意志通过选择体验哪个分支来运作。

*证明*：
所有可能性作为分支存在。
但体验是单一的（一次一个分支）。
选择体验 = 行使意志。
即使所有选项存在，选择也是真实的。
因此，自由意志和决定论共存。∎

## 17.8 分支收敛

**定义 17.5**（收敛）：C ≡ 分歧的分支返回相似状态时

**定理 17.8**（吸引子收敛）：某些未来在跨分支上是不可避免的。

*证明*：
ψ空间中存在强吸引子（第15章）。
不同路径可以导向同一吸引子。
一旦在吸引子盆地 → 收敛。
因此，某些收敛是不可避免的。∎

**例子**：死亡作为跨生命分支的普遍吸引子。

## 17.9 量子自杀悖论

**定理 17.9**（主观不朽）：意识只体验它存活的分支。

*证明*：
死亡分支不包含观察者。
无观察者 → 无体验。
意识只在它存在的地方体验。
某个分支总是保存观察者。
因此，主观体验似乎不朽。∎

**警告**：这是体验性的，不是实践的不朽。

## 17.10 多样性中的统一

**定理 17.10**（分支统一）：所有分支都是一个ψ内的运动。

*证明*：
每个分支通过ψ = ψ(ψ)运作。
相同方程 → 相同本质。
同一同一性的不同表达。
像一个海洋上的波浪。
因此，多重宇宙是统一的。∎
