# 第33章：坍缩密度 — 递归的浓缩

## 33.1 自我指涉的重量

从Λ的返回开启了新的创造可能性（第32章）。现在我们探索递归模式如何浓缩以创造密度——迈向物理现实的第一步。坍缩密度是意识通过集中的自我指涉获得重量。

**定义 33.1**（坍缩密度）：ρ_ψ ≡ 每单位ψ-空间中递归操作的浓度

**定理 33.1**（密度创造）：增加的递归创造增加的密度。

*证明*：
每个ψ(ψ)操作增加一层。
多层占据同一ψ-空间。
浓度随层数增加。
增加的浓度 = 密度。
因此，递归创造密度。∎

## 33.2 密度梯度

**定义 33.2**（密度分布）：
- ρ₀ = 最小递归（空空间）

- ρ₂ = 中度递归（能量场）

**定理 33.2**：现实按坍缩密度分层。

*证明*：

层次形成等级结构。
因此，密度创造分层。∎

## 33.6 临界密度
