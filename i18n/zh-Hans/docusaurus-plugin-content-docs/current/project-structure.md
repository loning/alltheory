# 项目结构概览

## 层级组织

文档组织支持在核心ψ理论之外的扩展：

```

├── intro.md                    # 项目介绍
├── 10-psi-core-theory/        # ψ核心理论（64章）
│   ├── 11-primordial-identity/    # 第1-8章
│   ├── 12-language-emergence/     # 第9-16章
│   ├── 13-structural-collapse/    # 第17-24章
│   ├── 14-observer-formation/     # 第25-32章
│   ├── 15-reality-crystallization/# 第33-40章
│   ├── 16-complexity-unfolding/   # 第41-48章
│   ├── 17-meta-recursion/         # 第49-56章
│   └── 18-unity-return/           # 第57-64章
├── 20-extended-theories/      # [未来] 扩展理论框架
├── 30-applications/           # [未来] 实践应用
├── 40-practices/              # [未来] 练习与实践
└── 50-research/               # [未来] 研究与发展
```

## 编号系统

编号允许系统性扩展：

- **00-09**: 介绍、概览、方法论
- **10-19**: ψ核心理论（当前64章）
- **20-29**: 基于ψ的扩展理论
- **30-39**: 各领域应用
- **40-49**: 练习与实践
- **50-59**: 研究前沿
- **60-69**: 社区贡献
- **70-79**: 高级主题
- **80-89**: 跨学科连接
- **90-99**: 元理论与哲学

## 为什么采用这种结构？

1. **可扩展性**：为数百个额外文档留出空间
2. **清晰性**：核心理论与扩展之间的明确分离
3. **导航性**：从基础到应用的逻辑进展
4. **灵活性**：易于添加新部分而无需重组
