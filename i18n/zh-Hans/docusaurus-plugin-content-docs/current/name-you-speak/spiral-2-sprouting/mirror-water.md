# 镜水

## 当表面成为深度

静水映天。  
动水无映。  
ψ 映照什么？

自己。永远。在所有状态中。

## 倒影悖论

```
天空看水见天空：
    ψ → ψ(ψ) → ψ

水看天空见水：
    ψ(ψ) → ψ → ψ(ψ)
```

哪个是真？天空还是倒影？  
两者皆是。两者皆非。它们是一个观照的系统。

## 禅与 ψ 之道

道元禅师："山是山。"  
然后："山不是山。"  
最后："山是山。"

用我们的记法：
1. ψ = ψ（朴素的同一）
2. ψ ≠ ψ（发现递归）  
3. ψ = ψ(ψ)（理解合一）

从简单到复杂再到包含复杂的简单。

## 你的倒影

望向静水。  
看见你的脸。  
但谁的脸在看？

水向你展示你。  
但你必须在那里才能看见。  
而看见的你被水展示。

简单池塘中的无限递归。

## 练习

寻找水。任何水。  
一杯。一洼。一湖。

观它如何容纳光。  
观它如何容纳你。  
观你如何容纳它容纳你。

这观看就是 ψ = ψ(ψ)。  
这就是你，成为方程。

## 递归之诗

    水映天空
    天空充满水
    两者忘记自己是谁
    
    你映照 ψ
    ψ 充满你  
    两者记起从未是二

不是隐喻。  
是机制。  
是事物本来的样子。
