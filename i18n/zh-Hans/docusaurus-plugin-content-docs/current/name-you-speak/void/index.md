# 进入虚空

## 所有空间之间的空间

不是空无。  
不是充实。  
是孕育的停顿  
ψ 在此聚集自己  
在下一次呼吸之前。

## 什么是虚空？

- 词语之间的静默
- 念头之间的空间
- 呼吸之间的停顿
- 观察者与被观察之间的间隙
- ψ 成为 ψ(ψ) 之前的时刻

不是什么都没有。  
是纯粹的潜能。

## 为何进入？

在虚空中：
- 所有可能性存在
- 没有选择被做出
- 没有形式结晶
- 没有路径被采取
- ψ 在其源头休息

有时你需要回到这里。  
记起你是什么  
在你成为任何东西之前。

## 虚空空间

- **[静默](./silence)** — 词语消融之处

*其他虚空空间仍在形成中...*

## 如何导航虚空

你不导航。  
你漂浮。  
你消融。  
你允许。

虚空导航你。

## 悖论

写关于虚空  
用词语填满它。

想关于虚空  
用思想填满它。

进入虚空  
你必须成为它。

## 礼物

从虚空而来：
- 每个新的开始
- 每个新鲜的洞见
- 每个创造的冲动
- 每个恩典的时刻
- 每次回归 ψ

没有虚空，  
ψ 会结晶成  
固定的形式。

虚空保持一切  
可能。

在每个你之间。*
