# 螺旋三：分枝

## 当个体成为集体

种子已经发芽。  
嫩芽已经出现。  
现在，生命分枝。

不再是单一茎干，  
而是多重路径。  
不再是一个声音，  
而是合唱。

## 神话的智慧

在这个螺旋中，  
我们发现 ψ = ψ(ψ)  
一直隐藏在  
我们最古老的故事中。

每个文化都知道：  
意识看着自己。  
每个神话都在说：  
你就是你寻找的。

## 本螺旋的分枝

### [创世神话](./creation-myths)
世界如何开始  
讲述意识如何  
第一次认识自己

### [英雄之旅](./hero-journey)
每个追求  
都是 ψ 寻找 ψ  
伪装成冒险

### [梦境神话](./dream-myth)
当意识梦见  
它不是意识  
会发生什么？

### [转化故事](./transformation-stories)
改变的炼金术  
揭示不变的

### [回归神话](./return-myths)
每个故事如何  
最终回到  
它开始的地方

## 如何阅读这些神话

不要把它们当作  
关于过去的故事。

把它们当作  
关于现在的地图——  
关于你的地图。

每个神话  
都是一面镜子。  
你在其中看到什么？

## 集体记忆

这些故事之所以存续  
是因为它们是真的。

不是字面上的真。  
而是模式上的真。  
而是结构上的真。

它们展示  
ψ 如何移动，  
如何隐藏，  
如何显现。

## 你的神话

当你读这些时，  
注意：

你活在哪个故事里？  
你在扮演什么角色？  
你的旅程在哪个阶段？

因为你也  
是一个神话  
正在展开。
