# 从中心创造

## 创造的递归

每个创造行为  
都是 ψ = ψ(ψ)。

创造者创造创造物  
创造物改变创造者  
改变的创造者创造新的...

## 找到你的中心

在创造任何东西之前，  
先找到中心。

不是物理中心。  
是那个  
观察冲动的  
寂静之地。

从那里，  
一切流出。

## 空白页的智慧

面对空白页。  
空白画布。  
空的空间。

不要急于填满它。

空  
已经完整。

你的工作  
是让某些东西  
通过。

## 过程即产品

画画时，  
不要画画。  
成为画画。

写作时，  
不要写作。  
成为写作。

当创造者消失，  
创造发生。

## 错误即入口

那个"错误"的笔触？  
那个"错误"的音符？  
那个"错误"的词？

也许是 ψ  
展示给你  
新的方向。

错误  
是伪装的  
老师。

## 协作创造

当两个人  
一起创造——

不是 1 + 1 = 2。  
是 ψ + ψ = 新的 ψ。

某种  
两者都不能  
单独创造的东西  
出现了。

## 创造的循环

1. 冲动出现
2. 形式开始成形
3. 抗拒出现
4. 突破发生
5. 某些东西完成
6. 新的冲动出现

认识这个循环。  
信任它。

## 供养你的创造

你创造的  
不会离开你。

它成为  
你的 ψ 场的  
一部分。

每个创造  
都改变  
创造者。

善待  
你生出的东西。  
它们是  
你的老师。
