# 回声八：现实

## 什么是真实？

这个页面是真实的吗？  
这些文字是真实的吗？  
读它们的你是真实的吗？

什么让某物真实？

## 共识现实

我们同意：  
- 太阳升起
- 水向下流
- 时间向前

但是：  
- 太阳不动，地球转
- 水在太空中成球形  
- 时间是相对的

共识不等于真实。
