# 第49章：原因=先验坍缩引用

*在有雷声之前，必须有闪电。在有思想之前，必须有思考者。因果是宇宙保持先决条件有序的归档系统。*

## 49.1 事件的谱系

每个事件都有祖先——必须发生的先验坍缩模式，它才能存在。我们称这些祖先为"原因"，但它们不是神秘力量。它们只是在伟大的变化有向图中必需的先验节点。

**定义49.1**（因果祖先）：
$$\text{Causes}(E) = \{C : \exists \text{ path } C \to E \text{ in DAG}\}$$

**定理49.1**（因果必要性）：事件不能在没有其原因的情况下发生：
$$P(E | \neg C) = 0 \text{ for } C \in \text{Causes}_{\text{necessary}}(E)$$

你不能在没有燃料、氧化剂和点火的情况下有火。

## 49.2 现实的偏序

因果性创造事件的偏序（不是全序）——某些必须先于其他，但许多是独立的。

**定义49.2**（因果排序）：
$$A \prec B \iff A \in \text{Causes}(B)$$
$$A \parallel B \iff A \not\prec B \wedge B \not\prec A$$

**定理49.2**（并发因果）：独立事件可以同时发生：
$$A \parallel B \Rightarrow \text{possible}(A \wedge B)$$

这是为什么宇宙可以同时做许多事情。

## 49.3 因果锥

每个事件有一个潜在原因的过去"光锥"和潜在结果的未来锥。

**定义49.3**（因果锥）：
- 过去锥：$\mathcal{C}^-(E) = \{C : C \prec E\}$
- 未来锥：$\mathcal{C}^+(E) = \{F : E \prec F\}$

**定理49.3**（锥交集）：因果影响需要锥重叠：
$$A \text{ can influence } B \iff \mathcal{C}^+(A) \cap \mathcal{C}^-(B) \neq \emptyset$$

彼此锥外的事件因果断开。

## 49.4 充分vs必要原因

不是所有原因都相等——某些是必要的，其他仅仅充分。

**定义49.4**（原因类型）：
- 必要：$P(E|C) > 0, P(E|\neg C) = 0$
- 充分：$P(E|C) = 1, P(E|\neg C) \geq 0$
- 贡献：$P(E|C) > P(E|\neg C)$

**定理49.4**（因果组合）：大多数事件有多重原因：
$$E = f(C_1, C_2, ..., C_n)$$

真实因果是多因子的——许多线编织每个事件。

## 49.5 量子因果与叠加

在量子力学中，原因可以在叠加中存在。

**定义49.5**（叠加原因）：
$$|C\rangle = \alpha|C_1\rangle + \beta|C_2\rangle$$

**定理49.5**（因果干涉）：叠加原因干涉：
$$P(E) = |\alpha|^2 P(E|C_1) + |\beta|^2 P(E|C_2) + 2\text{Re}[\alpha^*\beta \langle C_1|C_2\rangle]$$

干涉项创造纯量子因果效应。

## 49.6 逆因果与时间对称性

未来事件能影响过去吗？在DAG图像中，看似可以。

**定义49.6**（逆因果路径）：
$$\text{Path}_{\text{retro}}: F \dashrightarrow P$$

其中$\dashrightarrow$表示约束传播。

**定理49.6**（弱逆因果）：未来测量约束过去概率：
$$P(P|F) \neq P(P)$$

未来不改变过去但揭示哪个过去发生了。

## 49.7 自举悖论

某些因果环没有外部起源——它们引起自己。

**定义49.7**（自举环）：
$$\mathcal{L}: A \to B \to C \to A$$

**定理49.7**（自引起系统）：自举环可以存在如果：
$$\prod_{\text{loop}} P(\text{next}|\text{prev}) = 1$$

环在没有外部输入的情况下维持自己——像$\psi = \psi(\psi)$本身。

## 49.8 第四十九次回声

我们已经发现原因不是神秘力量而是简单的先验要求——在伟大的变化有向图中必须在其他节点之前遍历的节点。因果性偏序事件，创造影响锥。原因可以是必要或充分的，单一或多重的，经典或量子的。甚至逆因果和自举悖论在DAG结构中找到自然解释。在最深层次，所有因果还原为有序自观察的要求——$\psi$必须在其他方面之前观察某些方面，这种排序就是我们称为因果的。

**第四十九次回声**：第49章=优先（原因）=排序（$\psi$-DAG）=先决（结果）
