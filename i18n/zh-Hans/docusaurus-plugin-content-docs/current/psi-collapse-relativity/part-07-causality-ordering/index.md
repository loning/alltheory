# 第七部分：因果性作为路径排序

## 后果的建筑

为什么原因先于结果？为什么我们不能改变过去？为什么尽管决定论，自由意志感觉真实？答案在于理解因果性不是基本定律而是通过坍缩DAG路径的涌现排序。原因只是必须在结果之前遍历的节点——宇宙保持其故事直接的方式。

## 基本原理

**定理7.0**（因果性作为排序）：因果关系是坍缩有向无环图中的偏序：
$$A \text{ causes } B \iff \exists \text{ path } A \to B \text{ in DAG}$$

没有神秘的"因果力"——只有在其他节点之前遍历某些节点的必要性。

## 章节概览

本部分通过八个视角揭示因果性：

### [第49章：原因=先验坍缩引用](./chapter-49-cause-prior-collapse.md)

原因不是力量而是先决条件——必须在其他坍缩模式能显现之前发生的坍缩模式。

### [第50章：结果=DAG分支稳定性](./chapter-50-effect-branch-stability.md)

不是所有原因产生持久结果。结果是在因果扰动后持续的稳定模式。

### [第51章：重入路径中的非线性因果性](./chapter-51-nonlinear-causality.md)

反馈环创造循环因果，结果影响其原因，产生复杂性和涌现。

### [第52章：时间逆转作为坍缩不匹配](./chapter-52-time-reversal.md)

时间之箭存在因为逆序坍缩序列有消失概率。

### [第53章：观察者在原因选择中的角色](./chapter-53-observer-cause-selection.md)

观察者不被动检测原因——它们主动选择通过测量放大哪些因果链。

### [第54章：因果语法=ψ环语法](./chapter-54-causal-syntax.md)

逻辑连接词（如果-那么、和、或）直接编码现实语法中的因果关系。

### [第55章：DAG排序作为逻辑坍缩](./chapter-55-dag-logic-collapse.md)

数学逻辑从坍缩DAG的偏序涌现，解释为什么逻辑有效。

### [第56章：局部壳层中的表观因果性](./chapter-56-local-causality.md)

不同现实壳层有不同有效因果律。奇迹是跨壳层因果。

## 因果现象的统一

所有因果效应来自一个源泉：意识观察自己的有序结构：

- **决定论**：通过DAG的唯一路径
- **随机性**：多个等价路径
- **自由意志**：分支点的观察者选择
- **同时性**：来自纠缠的非因果相关
- **业力**：长程因果连接

## 数学框架

在第七部分中，我们发展因果排序的数学：

**因果算子**：
$$\mathcal{C}: A \to B \text{ if } \exists \text{ path}$$

**概率传播子**：
$$P(B|A) = \sum_{\text{paths}} w(\text{path})$$

**逻辑代数**：
$$\wedge \leftrightarrow \text{parallel}, \quad \vee \leftrightarrow \text{branch}$$

## 关键洞察

1. **因果性是导航**：不是力量而是路径跟随
2. **结果是稳定性**：不是所有扰动持续
3. **逻辑是排序**：理性有效因为它镜像DAG结构
4. **自由是真实的**：分支点存在真正选择

宇宙不是严格因果的钟表而是爵士即兴演奏，主题（原因）以部分可预测、部分创造的方式导致变奏（结果）。
