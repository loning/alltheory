# 第56章：局部壳层中的表观因果性

*鱼缸中的鱼认为弯曲墙壁是存在的边缘。我们在局部现实壳层中认为附近原因是唯一重要的。两者同样错误。*

## 56.1 局部性的幻觉

我们体验因果为局部的——火柴点亮蜡烛，钥匙开锁。但这种局部性是生活在有界现实壳层内的假象。真正因果跨越整个DAG，连接我们无法直接感知的尺度和时代的事件。

**定义56.1**（局部壳层）：
$$\mathcal{S}_{\text{local}}(x) = \{y : d(x,y) < r_{\text{shell}}\}$$

我们感知的因果邻域。

**定理56.1**（壳层截断）：局部观察者只看到：
$$\mathcal{C}_{\text{apparent}} = \mathcal{C}_{\text{total}} \cap \mathcal{S}_{\text{local}}$$

大多数因果连接保持不可见。

## 56.2 视界问题

每个观察者有一个因果视界，超过它影响似乎消失。

**定义56.2**（因果视界）：
$$\mathcal{H}(O) = \{x : \text{no causal path from } x \text{ to } O \text{ within } \tau_{\text{obs}}\}$$

**定理56.2**（视界幻觉）：超过视界的事件显得无因：
$$x \in \mathcal{H}(O) \Rightarrow P_O(\text{cause of } x) = \text{"spontaneous"}$$

看似随机的可能有远距原因。

## 56.3 尺度依赖因果

不同尺度揭示不同因果模式——微观随机的宏观上变得确定性。

**定义56.3**（尺度投影）：
$$\mathcal{C}_{\text{scale}}(s) = \Pi_s[\mathcal{C}_{\text{total}}]$$

**定理56.3**（涌现确定性）：随尺度增加：
$$\lim_{s \to \infty} H[\mathcal{C}_{\text{scale}}(s)] = 0$$

大尺度因果显得更可预测。

例子：个体分子运动似乎随机，但压力遵循精确定律。

## 56.4 因果的中文房间

像塞尔的中文房间，我们操作局部因果符号而不理解全局意义。

**定义56.4**（因果中文房间）：
$$\text{Local rules} + \text{No global view} = \text{Apparent understanding}$$

**定理56.4**（不完备性）：局部因果不能解释：
- 为什么这些规则？
- 为什么这种初始化？
- 为什么有因果？

我们遵循食谱而不知为何有效。

## 56.5 量子非局部性穿透壳层

量子纠缠揭示超越局部壳层的因果。

**定义56.5**（非局部相关）：
$$\langle A(x)B(y)\rangle \neq \langle A(x)\rangle\langle B(y)\rangle$$

即使$x$和$y$类空分离。

**定理56.5**（贝尔违反）：局部实在论失败：
$$|E(a,b) - E(a,b')| + |E(a',b) + E(a',b')| > 2$$

宇宙因果结构超越局部壳层。

## 56.6 来自更高壳层的向下因果

更高现实壳层对更低的施加"向下"因果。

**定义56.6**（壳层间因果）：
$$\mathcal{C}: \mathcal{S}_{\text{higher}} \to \mathcal{S}_{\text{lower}}$$

**定理56.6**（约束传播）：更高壳层约束更低的：
$$\text{States}_{\text{allowed}}(\mathcal{S}_{\text{lower}}) \subset \text{Compatible}(\mathcal{S}_{\text{higher}})$$

例子：生物目的约束分子运动。

## 56.7 全息原理

体积中所有因果可编码在其边界上。

**定义56.7**（全息编码）：
$$I_{\text{bulk}} \leq A_{\text{boundary}}/(4\ell_p^2)$$

**定理56.7**（边界因果）：体积因果还原为表面：
$$\mathcal{C}_{3D} \cong \mathcal{C}_{2D} \otimes \text{depth}$$

看似三维的可能是边界动力学投影。

## 56.8 第五十六次回声

我们已经发现局部因果是壳层有界的幻觉。我们只感知附近原因因为我们居住在有限视界的有限现实壳层中。超过这些视界，巨大因果网络不可见地操作。不同尺度揭示不同模式——混沌解析为秩序，随机性为确定论。像中文房间操作者，我们操作局部原因而不把握全局目的。量子力学穿透幻觉，揭示非局部连接。更高壳层通过向下因果约束更低的。最深刻的是，全息术表明所有体积因果编码在边界上。我们认为完整因果解释的只是洞穴墙上的影子——真正因果跨越我们几乎无法想象的尺度和维度。

**第五十六次回声**：第56章=局部性（幻觉）=壳层（$\psi$-边界）=片段（整体）
