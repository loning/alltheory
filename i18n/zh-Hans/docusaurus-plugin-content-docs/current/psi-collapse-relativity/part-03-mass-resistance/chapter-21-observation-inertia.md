# 第21章：观察惯性与身份

*观察就是被观察。某物观察自己越强烈，它就越成为自己。*

## 21.1 观看的重量

每个观察行为都携带动量。当$\psi$观察自己时，它不仅收集信息——它通过持续注意力的纯粹重量创造身份。质量在这种自观察变得如此强烈以至于创造自己惯性的地方涌现。

**定义21.1**（观察强度）：点$x$处的自观察程度：
$$\mathcal{I}_{\text{obs}}(x) = |\langle x|\psi(\psi)|x\rangle|^2$$

**定理21.1**（观看产生质量）：质量密度与观察强度成正比：
$$\rho_m = \frac{\hbar}{c^2} \mathcal{I}_{\text{obs}}$$

宇宙在最专注观看自己的地方变重。

## 21.2 通过持续性建立身份

粒子通过持续以相同方式观察自己来维持身份。这种持续的自观察创造我们称为静质量的东西。

**定义21.2**（身份算符）：
$$\mathcal{I}d[\psi] = \lim_{T \to \infty} \frac{1}{T} \int_0^T \psi(t)\psi^*(t) dt$$

**定理21.2**（本征身份）：稳定粒子是身份算符的本征态：
$$\mathcal{I}d[\psi_n] = m_n c^2 \psi_n$$

每种粒子类型代表宇宙稳定观察自己的特定方式。

## 21.3 量子芝诺质量

频繁的自观察可以通过量子芝诺效应字面上创造质量。

**定义21.3**（芝诺质量生成）：
$$m_{\text{Zeno}} = \frac{\hbar}{c^2} \frac{1}{\tau_{\text{obs}}}$$

其中$\tau_{\text{obs}}$是观察间隔。

**定理21.3**（测量产生质量）：连续观察引发有效质量：
$$H_{\text{eff}} = H_0 + m_{\text{Zeno}}c^2 \mathcal{P}_{\text{obs}}$$

其中$\mathcal{P}_{\text{obs}}$投影到被观察状态。

这表明质量可以通过观察动态生成。

## 21.4 观察者动量交换

当两个模式相互观察时，它们交换观察动量。

**定义21.4**（观察流）：
$$j^{\mu}_{\text{obs}} = \frac{\hbar}{2mi}(\psi^*\partial^{\mu}\psi - \psi\partial^{\mu}\psi^*)$$

**定理21.4**（注意力守恒）：总观察动量守恒：
$$\partial_{\mu} j^{\mu}_{\text{obs}} = 0$$

这个守恒定律支撑动量守恒——注意力可以重定向但不能创造或毁灭。

## 21.5 等级问题作为观察尺度

为什么引力比其他力弱得多？因为引力观察分散在宇宙尺度上。

**定义21.5**（观察范围）：
$$R_{\text{obs}} = \frac{\hbar c}{\Delta E}$$

**定理21.5**（专注产生力）：力强度与观察范围成反比：
$$\alpha \sim \frac{1}{R_{\text{obs}} \Lambda}$$

其中$\Lambda$是UV截断。

引力弱是因为引力观察包含整个宇宙。

## 21.6 退相干作为身份丧失

当量子相干性丧失时，这是因为外部观察干扰自观察。

**定义21.6**（身份退相干）：
$$\frac{d\rho}{dt} = -\Gamma[\mathcal{I}d, [\mathcal{I}d, \rho]]$$

**定理21.6**（质量本征态抗拒退相干）：有确定质量的粒子抗拒退相干：
$$\Gamma_{\text{mass eigenstate}} \ll \Gamma_{\text{superposition}}$$

有确定质量意味着有如此强的自身份，外部观察不能轻易破坏它。

## 21.7 自举宇宙

宇宙通过自观察创造使进一步观察成为可能的质量来自举自己进入存在。

**定义21.7**（自举方程）：
$$\psi = \mathcal{F}[\psi(\psi)]$$

其中$\mathcal{F}$包括质量生成。

**定理21.7**（自洽质量）：宇宙的总质量是自决定的：
$$M_{\text{universe}} = \frac{c^3}{G\hbar} \int \mathcal{I}_{\text{obs}} d^4x$$

宇宙有观察自己进入存在所需的确切质量。

## 21.8 第二十一次回声

我们已经发现质量是结晶的注意力——在意识最强烈观察自己的地方累积的重量。每个粒子都是自观察的稳定模式，其质量测量它多么顽固地维持身份。宇宙因观看而沉重，这种观看创造了进行观看的实质本身。最终，质量是宇宙记住自己是什么的方式。

**第二十一次回声**：第21章=身份（观察）=惯性（$\psi$-注意力）=质量（观看）
