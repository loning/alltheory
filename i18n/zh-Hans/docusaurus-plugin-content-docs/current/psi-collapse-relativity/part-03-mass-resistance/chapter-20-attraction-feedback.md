# 第20章：吸引作为反馈增强

*质量吸引质量不是通过神秘的超距作用，而是通过宇宙放大自身模式的倾向。*

## 20.1 阻抗的共振

当两个有质量物体存在于同一区域时，它们的坍缩阻抗模式不是简单相加——它们共振。这种共振创造正反馈，将它们拉向一起。引力不是力而是和谐。

**定义20.1**（坍缩共振）：两个阻抗模式间的相互作用：
$$\mathcal{R}_{12} = \langle\psi_1|\psi_2\rangle \cdot \mathcal{R}_1 \otimes \mathcal{R}_2$$

**定理20.1**（共振产生吸引）：共振模式创造吸引耦合：
$$F_{12} = -\nabla\mathcal{R}_{12} = -G\frac{m_1m_2}{r^2}\hat{r}$$

牛顿定律从重叠阻抗的几何中涌现。

## 20.2 引力束缚作为相位锁定

当质量相互轨道运动时，它们的坍缩模式像耦合振子一样相位锁定。

**定义20.2**（相位锁定态）：
$$\psi_{\text{bound}} = \psi_1(t)e^{i\phi_1} + \psi_2(t)e^{i\phi_2}$$

其中$\frac{d\phi_1}{dt} = \frac{d\phi_2}{dt} = \omega_{\text{orbit}}$

**定理20.2**（束缚能）：相位锁定释放能量：
$$E_{\text{binding}} = E_1 + E_2 - E_{\text{locked}}$$

引力波带走相位失配能量，因为模式同步。

## 20.3 聚集的正反馈

物质聚集是因为坍缩阻抗是超加性的——整体阻抗超过部分之和。

**定义20.3**（阻抗放大）：
$$\mathcal{R}_{\text{total}} = \sum_i \mathcal{R}_i + \sum_{i<j} \mathcal{A}_{ij}$$

其中$\mathcal{A}_{ij} > 0$是放大项。

**定理20.3**（失控聚集）：超过临界密度，聚集加速：
$$\frac{d\rho}{dt} = \alpha\rho^2 - \beta\rho$$

这导致结构形成——星系、恒星和行星是失控的反馈模式。

## 20.4 潮汐效应作为差分反馈

潮汐力在反馈强度跨延展体变化时产生。

**定义20.4**（潮汐张量）：
$$T_{ij} = \frac{\partial^2 \mathcal{R}}{\partial x_i \partial x_j}$$

**定理20.4**（意大利面化）：在强源附近，差分反馈撕裂物体：
$$\Delta F = T_{ij} \Delta x^j$$

黑洞潮汐效应是极端反馈梯度——不同部分体验截然不同的共振强度。

## 20.5 引力透镜作为反馈聚焦

质量弯曲光线是因为坍缩反馈创造折射率梯度。

**定义20.5**（反馈诱导折射）：
$$n(r) = 1 + \frac{2GM}{rc^2}$$

**定理20.5**（爱因斯坦环）：完美对准创造圆形反馈聚焦：
$$\theta_E = \sqrt{\frac{4GM}{c^2} \frac{d_{LS}}{d_L d_S}}$$

宇宙使用质量作为透镜来聚焦自己的自观察。

## 20.6 暗物质作为隐藏反馈

暗物质可能是不与电磁观察耦合的坍缩反馈模式。

**定义20.6**（暗反馈）：
$$\mathcal{R}_{\text{dark}} \perp \mathcal{R}_{\text{EM}}$$

**定理20.6**（仅引力耦合）：暗模式只影响引力反馈：
$$\mathcal{L}_{\text{interaction}} = \mathcal{R}_{\text{dark}} \cdot \mathcal{R}_{\text{gravity}}$$

暗物质晕是我们只能通过引力和谐探测的反馈模式。

## 20.7 负反馈与暗能量

物质创造正反馈（吸引），暗能量创造负反馈（排斥）。

**定义20.7**（反共振）：
$$\mathcal{R}_{\Lambda} = -\Lambda g_{\mu\nu}$$

**定理20.7**（宇宙加速）：负反馈驱动膨胀：
$$\frac{\ddot{a}}{a} = -\frac{4\pi G}{3}(\rho + 3p) + \frac{\Lambda}{3}$$

暗能量是宇宙防止完全坍缩成单一反馈模式的方式。

## 20.8 第二十次回声

我们已经揭示引力不是神秘的力，而是宇宙趋向模式增强的倾向。质量吸引质量是因为阻抗模式共振和放大。从原子间的轻柔拉力到黑洞的暴力合并，所有引力现象都源于自观察模式间的反馈。宇宙是一个巨大的共振室，每个质量都与其他质量和谐歌唱。

**第二十次回声**：第20章=吸引（反馈）=共振（$\psi$）=引力（和谐）
