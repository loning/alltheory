# 第31章：坍缩张量=爱因斯坦投影

*爱因斯坦方程不是基本的——它们是柏拉图洞穴墙上的影子，由ψ观察自己更深层舞蹈投射。*

## 31.1 从坍缩到曲率

爱因斯坦场方程关联时空曲率与能量-动量。但我们现在理解两边都从同一源涌现：自指坍缩模式。方程不是强加给自然的定律，而是自然对如何观察自己的簿记。

**定义31.1**（基本坍缩张量）：
$$\mathcal{C}_{\mu\nu} = \langle \partial_{\mu}\psi^{\dagger} \partial_{\nu}\psi \rangle - \frac{1}{2}g_{\mu\nu}\langle \partial^{\lambda}\psi^{\dagger} \partial_{\lambda}\psi \rangle$$

**定理31.1**（坍缩导出爱因斯坦）：爱因斯坦张量是投影：
$$G_{\mu\nu} = R_{\mu\nu} - \frac{1}{2}g_{\mu\nu}R = \frac{8\pi G}{c^4}\Pi[\mathcal{C}_{\mu\nu}]$$

其中$\Pi$投影到可观察时空。

## 31.2 自观察的应力-能量

我们称为能量-动量的真正是坍缩通过时空的流动。

**定义31.2**（坍缩流张量）：
$$T^{\psi}_{\mu\nu} = \frac{2}{\sqrt{-g}}\frac{\delta S_{\psi}}{\delta g^{\mu\nu}}$$

其中$S_{\psi} = \int \mathcal{L}_{\psi} \sqrt{-g} \, d^4x$是坍缩作用量。

**定理31.2**（能量作为强度）：能量密度等于坍缩强度：
$$T_{00} = \rho c^2 = \mathcal{I}_{\text{collapse}}$$

质量-能量字面上是$\psi$在每点观察自己的强度。

## 31.3 意识的里奇流

里奇张量描述体积在平行输运下如何变化——在我们框架中，坍缩模式如何演化。

**定义31.3**（里奇演化）：
$$\frac{\partial g_{\mu\nu}}{\partial t} = -2R_{\mu\nu}$$

**定理31.3**（坍缩平滑）：里奇流平滑坍缩不均匀性：
$$\mathcal{C}_{\mu\nu}(t) = e^{-2R_{\mu\nu}t}\mathcal{C}_{\mu\nu}(0)$$

宇宙趋向均匀自观察——这是空间在大尺度看起来平滑的原因。

## 31.4 韦尔张量与潮汐坍缩

里奇描述体积变化，韦尔描述形状扭曲——潮汐效应。

**定义31.4**（韦尔张量）：
$$C_{\mu\nu\rho\sigma} = R_{\mu\nu\rho\sigma} - \frac{1}{2}(g_{\mu\rho}R_{\nu\sigma} - \text{traces})$$

**定理31.4**（韦尔产生潮汐）：潮汐力从韦尔曲率产生：
$$\frac{D^2\xi^{\mu}}{D\tau^2} = C^{\mu}_{\nu\rho\sigma}u^{\nu}\xi^{\rho}u^{\sigma}$$

韦尔编码坍缩模式如何拉伸和挤压附近观察者。

## 31.5 比安基恒等式作为守恒

比安基恒等式确保曲率张量的一致性——在我们框架中，它是坍缩的守恒。

**定义31.5**（缩并比安基）：
$$\nabla^{\mu}G_{\mu\nu} = 0$$

**定理31.5**（自动守恒）：坍缩守恒从几何遵循：
$$\nabla^{\mu}T_{\mu\nu} = 0$$

能量-动量守恒因为坍缩模式必须自洽。

## 31.6 爱因斯坦的量子修正

在量子尺度，平滑的爱因斯坦张量从坍缩涨落获得修正。

**定义31.6**（量子爱因斯坦张量）：
$$G^{\text{quantum}}_{\mu\nu} = G_{\mu\nu} + \hbar G^{(1)}_{\mu\nu} + \hbar^2 G^{(2)}_{\mu\nu} + ...$$

**定理31.6**（涨落修正）：领头量子修正：
$$G^{(1)}_{\mu\nu} = \alpha \langle R_{\mu\rho}R^{\rho}_{\nu} \rangle - \beta g_{\mu\nu}\langle R^2 \rangle$$

量子引力是经典引力加坍缩涨落。

## 31.7 宇宙学常数之谜

为什么宇宙学常数如此小？因为它测量宇宙的基线自观察速率。

**定义31.7**（真空坍缩）：
$$\Lambda = 8\pi G \langle 0|\mathcal{C}_{\mu\nu}|0 \rangle g^{\mu\nu}$$

**定理31.7**（人择调节）：$\Lambda$必须允许复杂坍缩模式：
$$\Lambda \sim H_0^2 \sim (10^{-33} \text{ eV})^2$$

太大，坍缩模式分散。太小，它们过度集中。我们存在于狭窄窗口中。

## 31.8 第三十一次回声
