# 第29章：观察者坍缩曲线

*每个观察者在坍缩景观中雕刻自己的路径——对一个弯曲的，对另一个可能是直线。*

## 29.1 曲率的相对性

爱因斯坦的伟大洞察是引力是相对的——自由下落的观察者感受不到力。在我们的框架中，这是因为每个观察者定义自己的坍缩基线，将偏离其自然路径体验为曲率。

**定义29.1**（观察者参考系）：观察者的自然坍缩状态：
$$|\mathcal{O}\rangle = \sum_i c_i|i\rangle$$

定义他们局部的"直线"路径。

**定理29.1**（等价原理）：局部地，引力与加速度无法区分：
$$g_{\mu\nu}^{\text{local}} = \eta_{\mu\nu} + O(x^2)$$

每个观察者都可以选择他们在平坦时空中静止的坐标——至少局部如此。

## 29.2 费米标准坐标

围绕任何世界线，我们可以构造观察者感受不到引力的坐标。

**定义29.2**（费米坐标）：
$$x^{\mu}_{\text{Fermi}} = \int_0^{\tau} e^{\mu}_a(\tau') n^a d\tau'$$

其中$e^{\mu}_a$是正交标准基矢量。

**定理29.2**（局部平坦性）：在费米坐标中：
$$\Gamma^{\mu}_{\nu\lambda}|_{\text{worldline}} = 0$$

观察者的世界线在自己的坐标中是"直的"——曲率总是在别处。

## 29.3 林德勒视界

加速观察者即使在平坦时空中也经历视界——与他们因果断开的区域。

**定义29.3**（林德勒度规）：
$$ds^2 = -\rho^2 d\eta^2 + d\rho^2 + dx_{\perp}^2$$

其中$\rho = x/a$和$\eta = at$。

**定理29.3**（加速视界）：匀加速观察者看到：
$$\text{Horizon at } \rho = 0$$

超出此处，没有信号能追上。加速创造自己的事件视界。

## 29.4 昂鲁效应

加速观察者在惯性观察者看到真空的地方看到粒子——加速加热空虚空间。

**定义29.4**（昂鲁温度）：
$$T_{\text{Unruh}} = \frac{\hbar a}{2\pi k_B c}$$

**定理29.4**（观察者依赖的真空）：粒子内容取决于运动：
$$\langle n \rangle_{\text{acc}} = \frac{1}{e^{2\pi\omega/a} - 1}$$

不同观察者字面上对什么存在持不同意见——现实是观察者相对的。

## 29.5 对延展观察者的潮汐效应

真实观察者有尺寸，在不同点经历不同引力——潮汐力。

**定义29.5**（偏差方程）：
$$\frac{D^2\xi^{\mu}}{D\tau^2} = -R^{\mu}_{\nu\rho\sigma}u^{\nu}\xi^{\rho}u^{\sigma}$$

其中$\xi$是分离矢量。

**定理29.5**（面条化）：在强场附近，观察者拉伸：
$$\Delta F \sim \frac{2GMl}{r^3}$$

其中$l$是观察者的长度。

接近黑洞，你被差分观察撕裂。

## 29.6 观察者依赖的熵

不同观察者为同一区域分配不同熵——熵是观察者相对的。

**定义29.6**（纠缠熵）：
$$S_{\mathcal{O}} = -\text{Tr}[\rho_{\mathcal{O}} \ln \rho_{\mathcal{O}}]$$

其中$\rho_{\mathcal{O}}$是观察者$\mathcal{O}$的约化密度矩阵。

**定理29.6**（熵相对性）：加速观察者看到热熵：
$$S_{\text{acc}} = \frac{A}{4\ell_P^2}$$

对其视界面积$A$。

信息在观察者眼中。

## 29.7 量子参考系

在量子引力中，观察者自己是量子的——不同视角的叠加。

**定义29.7**（量子观察者）：
$$|\mathcal{O}\rangle = \sum_i \alpha_i |g_i\rangle |\psi_i\rangle$$

其中$|g_i\rangle$是不同几何。

**定理29.7**（视角叠加）：量子观察者看到叠加现实：
$$|\text{Reality}_{\mathcal{O}}\rangle = \sum_i \alpha_i |\text{Reality}_i\rangle$$

量子观察者没有确定视角——他们处于体验不同曲率的叠加中。

## 29.8 第二十九次回声

我们已经揭示曲率，如美丽，在观察者眼中。每个意识在坍缩景观中雕刻自己的路径，体验自己版本的直与弯、力与自由落体。一个观察者称为引力，另一个称为加速度。一个看到的粒子，另一个看到真空。宇宙没有绝对几何——只有不同观察者导航自己坍缩曲线时视角的相互作用。

**第二十九次回声**：第29章=视角（曲线）=相对性（$\psi$-路径）=民主（观察者）
