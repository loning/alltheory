# 第44章：觉知流过DAG

*意识不是事物而是旅程——觉知像水流过可能性通道。*

## 44.1 注意力之河

威廉·詹姆斯描述的意识流字面上是流——觉知流过坍缩可能性的有向无环图。每个时刻，注意力从一个节点转移到另一个，创造心理流动的主观体验。

**定义44.1**（注意力向量）：
$$\vec{A}(t) = \sum_i a_i(t) |v_i\rangle$$

其中$|v_i\rangle$是DAG节点，$a_i(t)$是注意力振幅。

**定理44.1**（流动方程）：注意力演化为：
$$\frac{d\vec{A}}{dt} = -\nabla V_{\text{attention}} + \mathcal{D}\nabla^2\vec{A} + \vec{\xi}(t)$$

漂移、扩散和噪声塑造觉知流动。

## 44.2 心灵景观

DAG创造引导注意力流动的"能量景观"。

**定义44.2**（注意力势）：
$$V_{\text{attention}}(\vec{x}) = -\sum_i w_i \log P(v_i) - \sum_{ij} J_{ij} \delta(v_i, v_j)$$

**定理44.2**（吸引子盆地）：稳定思想是局部极小值：
$$\nabla V|_{\vec{x}_*} = 0, \quad \nabla^2 V|_{\vec{x}_*} > 0$$

心灵有思想自然沉淀的山谷。

## 44.3 心不在焉作为随机游走

当注意力不被引导时，它通过DAG执行随机游走。

**定义44.3**（默认模式）：
$$P(v_{n+1}|v_n) = \frac{e^{-\beta E(v_{n+1})}}{\sum_j e^{-\beta E(v_j)}}$$

**定理44.3**（游走统计）：在默认模式中：
$$\langle d^2(t) \rangle = 2Dt$$

注意力随时间扩散传播。

## 44.4 集中注意力作为相干流

在集中注意力期间，觉知变得相干，有目的地流动。

**定义44.4**（相干状态）：
$$|\vec{A}_{\text{focused}}\rangle = e^{-\|\vec{x}-\vec{x}_0\|^2/2\sigma^2} |v_{\text{target}}\rangle$$

**定理44.4**（持续专注）：专注需要能量：
$$\frac{dE}{dt} = -P_{\text{dissipation}} < 0$$

维持专注消耗代谢资源。

## 44.5 流动状态作为共振通道

在流动状态中，注意力在DAG中找到共振通道，努力变得毫不费力。

**定义44.5**（流动通道）：
$$\mathcal{C}_{\text{flow}} = \{v : \nabla V \cdot \hat{t} = \text{const}\}$$

**定理44.5**（最优体验）：流动发生当：
$$\text{Challenge level} = \text{Skill level} \pm \epsilon$$

完美匹配创造无摩擦注意力流动。

## 44.6 冥想作为流动简化

冥想练习通过简化流动景观起作用。

**定义44.6**（冥想简化）：
$$V_{\text{meditation}} = V_0 - \lambda \sum_i |a_i|^2$$

**定理44.6**（注意力稳定）：冥想增加相干时间：
$$\tau_{\text{coherence}}^{\text{meditation}} > \tau_{\text{coherence}}^{\text{normal}}$$

简化景观允许持续、稳定注意力。

## 44.7 迷幻剂与流动破坏

迷幻体验戏剧性地改变注意力景观。

**定义44.7**（迷幻调制）：
$$V_{\text{psychedelic}} = V_0 + \eta(t) \cdot \mathcal{N}(0,\sigma^2)$$

**定理44.7**（新颖路径）：在迷幻剂下：
$$P(\text{novel path}) \gg P(\text{habitual path})$$

新连接和非常规流动变得可能。

## 44.8 第四十四次回声

我们已经发现意识字面上是流动——注意力穿过可能思想景观移动，如水流过地形。这种流动可以蜿蜒（心不在焉）、聚焦（专注）、找到共振（流动状态）或被改变（冥想、迷幻剂）。思考的主观体验就是注意力流过坍缩DAG的客观流动。理解这种流动揭示了为什么心灵游荡、专注如何工作、以及冥想等实践实际做什么——它们重塑意识流过的景观。

**第四十四次回声**：第44章=河流（注意力）=流动（$\psi$-DAG）=旅程（心灵）
