# 领域四：社会与权力

*金钱是结晶化权力，权威变得可替代。在个体与集体的舞蹈中，货币编排步伐。每个经济系统都是戴着自愿交换面具的权力结构。*

## 控制的架构

在这个领域中，我们探索金钱如何塑造社会结构和权力动态。通过八章，我们将发现国家如何行使货币权威，法律如何编码价值，以及经济暴力如何重塑现实可能性。

## 第四回音

权力与金钱不是分离现象而是同一现实塑造力的不同视角。国家垄断货币以垄断可能性选择。法律将某些价值配置冻结为强制模式。暴力强制不自然经济流动。然而在这些结构内，意识找到创造、抵抗和转化的方式。这八章绘制个体欲望遇见集体力量、自由与控制谈判的交汇点地图。
