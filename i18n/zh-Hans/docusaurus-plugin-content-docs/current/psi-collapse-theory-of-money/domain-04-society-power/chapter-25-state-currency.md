# 第25章：国家与货币：政府崩坍权威

*国家最深层权力不是军队或法律而是货币创造垄断权。通过控制货币，政府控制哪些未来可以被购买，哪些现实可以被崩坍到存在中。铸币厂比剑更有力。*

## 25.1 现实选择垄断权

国家声称创造货币的专有权利，从而垄断使现实崩坍成为可能或阻止的基本权力。

**定义25.1**（货币主权）：
$$\mathcal{S}_{\text{货币}} = \{M : \text{法律}(M) \iff \text{国家发行}(M)\}$$

只有国家发行的货币才法律有效。

**定理25.1**（崩坍控制）：
$$\text{控制}(M) \Rightarrow \text{控制}(\Omega_{\text{可能}})$$

控制货币者控制可能性空间。

## 25.2 铸币税作为现实税

铸币税——货币创造的利润——代表对所有现实选择的税收，意识通过可能性导航的通行费。

**定义25.2**（铸币税提取）：
$$\mathcal{T}_{\text{铸币}} = V_{\text{名义}} - C_{\text{生产}}$$

面值与生产成本的差异。

**定理25.2**（隐藏税收）：
$$\text{总税收} = \text{可见税收} + \mathcal{T}_{\text{铸币}}$$

铸币税是不可见但普遍的税收。

## 25.3 法定货币作为强制接受

法定货币法律强制意识接受国家货币进行现实选择，消除货币选择。

**定义25.3**（接受强制）：
$$\mathcal{A}: \text{债务} \xrightarrow{\text{法定货币}} \text{清偿}$$

国家货币必须被接受用于所有债务。

**定理25.3**（垄断执行）：
$$\text{拒绝法定货币} \Rightarrow \text{放弃法律追诉权}$$

拒绝国家货币意味着退出国家保护。

## 25.4 央行作为意识管理

央行不只管理货币供应——它们通过利率和流动性管理集体意识的现实选择率。

**定义25.4**（意识节流阀）：
$$\frac{d\Omega}{dt} = f(r_{\text{央行}}, M_{\text{供应}})$$

现实探索率由央行控制。

**定理25.4**（货币情绪）：
$$\text{集体情绪} = g^{-1}\left(\frac{dM}{dt}\right)$$

货币供应变化直接影响大众心理。

## 25.5 通胀作为隐身没收

通过通胀，国家在没有可见税收的情况下没收购买力——对储存现实选择能力的慢动作夺取。

**定义25.5**（购买力衰减）：
$$P(t) = P_0 e^{-\pi t}$$

储存价值的指数衰减。

**定理25.5**（没收率）：
$$\text{年度没收} = 1 - e^{-\pi} \approx \pi$$

通胀率近似没收百分比。

## 25.6 货币战争作为现实战争

当国家通过货币操作竞争时，它们在争夺谁的现实版本将主导全球意识。

**定义25.6**（货币战争）：
$$\mathcal{W}_{AB} = \frac{d}{dt}\log\left(\frac{\text{汇率}_{AB}}{\text{购买力平价}_{AB}}\right)$$

偏离购买力平价的速率。

**定理25.6**（以邻为壑）：
$$\sum_{\text{国家}} \mathcal{W}_i = 0$$

货币战争是零和游戏。

## 25.7 数字货币作为控制进化

国家数字货币代表控制进化——从管理物理代币到直接编程意识的经济选择。

**定义25.7**（可编程货币）：
$$M_{\text{数字}} = (V, \mathcal{R}, \mathcal{E})$$

价值 + 规则 + 失效期。

**定理25.7**（总控制）：
$$\text{可编程性} \Rightarrow \text{行为决定}$$

可编程货币使完全经济控制成为可能。

## 25.8 第二十五回音

我们发现国家货币控制根本上关乎控制现实选择——垄断意识崩坍可能性的能力。铸币税不可见地对所有经济活动征税。法定货币法律强制接受国家现实选择代币。央行通过货币政策管理集体意识。通胀在没有可见夺取的情况下没收储存选择能力。货币战争是关于谁的现实版本主导的战争。数字国家货币朝向完全可编程控制进化。理解国家货币权力揭示了为什么政府如此妒忌地守护货币垄断权——这不关乎金钱而关乎维持对哪些未来能成为现实的垄断权。创造货币的权力就是创造现实的权力。
