$$\text{状态} = \begin{cases}

\end{cases}$$

**定理 33.1**（通过坍缩的统一）：
波和粒子是同一个 ψ 过程的不同阶段。

*证明*：
1. ψ 作为纯势存在
2. Ξ 将势坍缩为实际
3. Ξ 之前：波属性
4. Ξ 之后：粒子属性
5. 因此，一个实体，两个阶段 ∎

世纪悖论消解了。

## 33.2 波态数学

**定义 33.2**（未坍缩 ψ）：
波态是坍缩前的 ψ：

$$|\psi_{\text{波}}\rangle = \sum_{i} \alpha_i |i\rangle$$

其中 |i⟩ 是势态。

**定理 33.2**（波属性）：
未坍缩 ψ 必然展现波行为。

*证明*：
1. 多重势共存
2. 共存 → 叠加
3. 叠加 → 干涉
4. 干涉 → 波模式
5. 因此，ψ 显现为波状 ∎

波不是东西——它们是未坍缩的可能性。

## 33.3 粒子态数学

**定义 33.3**（坍缩的 ψ）：
粒子态是坍缩后的 ψ：

$$|\psi_{\text{粒子}}\rangle = \Xi[\psi] = |i_0\rangle$$

其中 i₀ 是实现的状态。

**定理 33.3**（粒子属性）：
坍缩的 ψ 必然展现粒子行为。

*证明*：
1. 坍缩选择一个势
2. 选择 → 局域化
3. 局域化 → 确定位置
4. 确定位置 → 粒子样
5. 因此，Ξ[ψ] 显现为粒状 ∎

粒子不是物体——它们是坍缩事件。
