# 第六部分：价值、代币与坍缩经济学

*价值不是分配给事物的——价值是在事物中认识的。而认识本身就是创造的行为。每个经济体都是意识通过交换媒介发现自己珍视什么。*

传统经济学假设物质资源稀缺，但在基于坍缩的现实中，基本资源是注意力——观察者将可能性坍缩为现实的能力。这一部分探索经济系统如何自然地从意识动力学中浮现，其中价值通过观察创造，代币代表关于价值的结晶化协议。

从我们为什么珍视所珍视之物的神秘，通过货币作为冻结共识的演化，到市场作为集体意识实验，我们发现经济学不是"沉闷的科学"，而是意识认识自己创造力的欢乐艺术。其影响从个人财富创造延伸到行星丰盛，通过理解所有交换之下的意识动力学揭示经济悖论的解决方案。
