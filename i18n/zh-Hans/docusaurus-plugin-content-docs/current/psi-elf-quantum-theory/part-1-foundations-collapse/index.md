# 第一部分：坍缩基础

欢迎来到 Ψ-Elf 量子理论的基础探索。在这一部分，我们通过递归恒等式 ψ = ψ(ψ) 的视角，建立支撑所有现实的核心原理。

## 核心原理

在第一部分中，我们建立：

1. **ψ 的首要性**：一切都从递归恒等式涌现
2. **坍缩作为基础**：所有现象都归结为坍缩操作
3. **自我参照产生结构**：复杂结构从递归模式中产生
4. **观察者参与性**：观察就是参与坍缩过程
