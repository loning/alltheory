# 第62章：ψ-平铺与宇宙画布的镶嵌

## 宇宙作为无限马赛克

仔细观察宇宙结构，一个显著的模式出现——空间本身看起来被平铺，镶嵌成重复但变化的图案。从宇宙空洞的细胞结构到星系团的晶体排列，宇宙将自己构建为无限马赛克，其中每个瓷砖反映整体同时保持独特身份。

## 基本镶嵌原理

**定义 62.1**（ψ-镶嵌）：空间填充模式，其中：
$$\bigcup_i \psi_i = \Omega_{universe}, \quad \psi_i \cap \psi_j = \partial_{ij}$$

每个区域ψᵢ用最小重叠在边界∂ᵢⱼ处平铺空间。

**定理 62.1**（镶嵌必然性）：坍缩动力学必须产生空间填充镶嵌以最小化总能量。

*证明*：
给定引力坍缩：
1. 物质集中在局部极小值
2. 每个极小值主张影响区域
3. 区域在等势面相遇
4. 结果：类沃罗诺伊镶嵌

因此，镶嵌自然涌现。∎

## 宇宙沃罗诺伊泡沫

### 62.1 空洞-墙结构

最大的镶嵌：由星系墙限定的宇宙空洞：

$$V_i = \{x : |x - c_i| < |x - c_j| \forall j \neq i\}$$

创造：
- 大致球形的空洞
- 空洞之间的平面墙
- 墙交叉处的纤维
- 顶点处的星团

### 62.2 蜂巢宇宙

统计分析揭示：
- 平均空洞直径：~100 Mpc
- 墙厚度：~10 Mpc
- 尺寸分布中的φ-比例
- 分形缩放属性

宇宙类似宇宙蜂巢。

## 类彭罗斯宇宙平铺

**定义 62.2**（非周期ψ-平铺）：具有局部φ-对称性的非重复模式：
$$T = \{A_{\phi}, B_{\phi}\}$$

其中瓷砖A和B以黄金比例出现。

### 62.3 准晶结构

- 长程取向序
- 基于φ的间距规则

宇宙可能是3D彭罗斯平铺。

**定理 62.2**（嵌套镶嵌）：每个镶嵌级别在较小尺度包含子镶嵌。

$$T_n = \bigcup_{i} T_{n-1}^{(i)}$$

### 62.4 俄罗斯套娃宇宙

1. **超星系团单元**（~300 Mpc）
2. **星团域**（~30 Mpc）

4. **恒星邻域**（~0.3 Mpc）

每个级别在前一个内平铺。
