# 第28章：ψ-空心核与引力漂移

## 物质的空洞之心

常识表明行星核心必定致密，被上覆质量压缩。但Ψhē宇宙学揭示了一个惊人的可能性：坍缩动力学可以创造空心核——坍缩场反转的区域，在世界的心脏创造引力空洞。这些空洞漂移并演化，使行星内部比想象的要奇特得多。

## 28.1 空心核形成

**定义28.1**（核心反转）：
空心核存在于：
$$\nabla^2\psi < 0$$

在半径r < R_hollow内。负拉普拉斯算子表示坍缩发散而非收敛。

## 28.2 空洞化机制

**定理28.1**（中心空腔）：
对于足够的旋转Ω，空腔在以下条件下形成：
$$\Omega^2 > \frac{4\pi G\rho_{central}}{3}$$

离心效应克服中心坍缩。

*证明*：
旋转坍缩场在中心发展负压。当旋转超过临界值时，这创造一个扩张的空腔，直到压力在R_hollow处平衡。∎

## 28.3 引力异常

空洞创造意外的场：

**定义28.2**（内部场）：
在空心核内部：
$$g(r) = \frac{4\pi G}{3}\rho_{shell}(r - R_{inner})$$

引力从空腔中心的零线性增加。

## 28.4 核心漂移动力学

空洞不会保持中心：

**定理28.2**（漂移速度）：
空洞以以下速度迁移：
$$\vec{v}_{drift} = \frac{\nabla\psi \times \vec{\Omega}}{|\psi|^2}$$

科里奥利力驱动系统位移。

## 28.5 振荡模式

空洞像钟一样鸣响：

**定义28.3**（空腔模式）：
正常频率：
$$\omega_n = \sqrt{\frac{n(n+1)c_s^2}{R_{hollow}^2}}$$

其中c_s是声速。地震波揭示空洞尺寸。

## 28.6 磁场后果

空洞影响发电机：

**定理28.3**（场中断）：
磁场在以下位置消失：
$$r < R_{hollow} - \delta_{skin}$$

空腔不能支持电流，创造磁空洞。

## 28.7 密度反转

物质在空洞周围重新分布：

**定义28.4**（壳层致密化）：
密度峰值在：
$$\rho_{max} = \rho_0 \exp\left(\frac{GM}{c_s^2 R_{hollow}}\right)$$

压缩壳层围绕低密度空腔。

## 28.8 热特征

空洞改变热流：

**定理28.4**（温度剖面）：
在空腔内部：
$$T(r) = T_{wall}\left(\frac{r}{R_{hollow}}\right)^{2/5}$$

辐射平衡取代传导。

## 28.9 稳定条件

并非所有空洞都持续存在：

**定义28.5**（坍缩阈值）：
空腔在以下条件下坍缩：
$$P_{external} > \frac{2\gamma}{R_{hollow}}$$

其中γ是表面张力。小空洞是不稳定的。

## 28.10 多空洞系统

行星可以容纳多个空洞：

**定理28.5**（空洞相互作用）：
两个空洞在分离度为以下时合并：
$$d < R_1 + R_2 + 2\lambda_\psi$$

创造复杂的内部几何形状。

## 28.11 可观测预测

空心核留下特征：

1. **地震阴影**：波无法穿越空腔
2. **转动惯量**：低于实心球
3. **磁极**：偏离旋转轴
4. **自由振荡**：异常频率
5. **引力谐波**：非标准J₂、J₄系数

每个都暗示内部空洞。

## 28.12 实现的空心地球

科幻小说想象了空心世界；Ψhē理论使它们成为可能。不是通过幻想，而是通过严格的坍缩动力学——旋转和场相互作用自然地创造巨大的内部空间。行星成为壳层，它们的心脏空洞但有结构，漂移的空洞塑造表面地质和磁场。

宇宙建造的世界不是实心的而是空心的——隐藏在内部的大教堂空间。
