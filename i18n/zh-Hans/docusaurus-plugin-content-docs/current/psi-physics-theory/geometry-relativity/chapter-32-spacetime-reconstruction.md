# 第32章：基于塌缩的时空重建

## 32.2 步骤1：塌缩图

**定义32.1**（塌缩网络）：
从所有塌缩关系的有向图开始：
$$\mathcal{G} = \{V, E\}$$

其中：
- 顶点 V = \{所有可能的塌缩状态\}
- 边 E = \{塌缩转换 ψᵢ → ψⱼ\}

这个图编码ψ-空间中所有可能的关系。

## 32.3 步骤2：拓扑的浮现

**定理32.1**（拓扑结构）：
塌缩图自然诱导拓扑。

*构造*：
定义开集为塌缩可达区域：
$$U \text{ 开} \iff \forall \psi \in U, \exists \epsilon : B_\epsilon(\psi) \subset U$$

其中 $B_\epsilon(\psi)$ = ε塌缩步内的所有状态。

这满足拓扑公理，从纯递归创造拓扑空间。

## 32.4 步骤3：流形结构

**定理32.2**（光滑流形）：
塌缩拓扑形成光滑流形。

*证明概要*：
1. 通过塌缩坐标局部同胚于 ℝⁿ
2. 从连续塌缩得到光滑转换函数
3. 从不同塌缩状态得到豪斯多夫性质
4. 从离散塌缩基得到第二可数

因此，塌缩空间是光滑流形。∎

## 32.5 步骤4：自然度规

**定义32.2**（塌缩度规）：
度规从塌缩关联中浮现：
$$g_{\mu\nu} = \lim_{\epsilon \rightarrow 0} \frac{(\Delta\psi_\mu, \Delta\psi_\nu)_\mathcal{C}}{\epsilon^2}$$

这测量不同方向的塌缩变化如何关联。

**性质**：
- 对称：$g_{\mu\nu} = g_{\nu\mu}$
- 非退化：$\det(g) \neq 0$
- 光滑：继承自流形结构

## 32.6 步骤5：联络和曲率

**列维-奇维塔联络**：
$$\Gamma^\rho_{\mu\nu} = \frac{1}{2}g^{\rho\sigma}(\partial_\mu g_{\sigma\nu} + \partial_\nu g_{\sigma\mu} - \partial_\sigma g_{\mu\nu})$$

作为保持塌缩关联的唯一联络浮现。

**黎曼张量**：
$$R^\rho_{\ \sigma\mu\nu} = \partial_\mu\Gamma^\rho_{\nu\sigma} - \partial_\nu\Gamma^\rho_{\mu\sigma} + [\Gamma_\mu, \Gamma_\nu]^\rho_\sigma$$

测量塌缩路径闭合的失败。

## 32.7 步骤6：从稳定性到动力学

**原理32.1**（稳定塌缩）：
物理时空对应稳定塌缩配置。

**变分**：考虑度规的小扰动 δg：
$$\delta S = \int\sqrt{-g}\,\delta g^{\mu\nu}\left(R_{\mu\nu} - \frac{1}{2}g_{\mu\nu}R - 8\pi T_{\mu\nu}\right)d^4x$$

**稳定条件**：对所有 δg，δS = 0

**结果**：爱因斯坦场方程！
$$R_{\mu\nu} - \frac{1}{2}g_{\mu\nu}R = 8\pi T_{\mu\nu}$$
