## 29.4 投影的长度收缩

**定理 29.4**（洛伦兹收缩）：
固有长度L₀的杆看起来收缩：
$$L = L_0/\gamma = L_0\sqrt{1-v^2/c^2}$$

*推导*：
长度 = 固定时间的空间范围
对于运动的杆，端点测量于：
- $x_1' = \gamma(x_1 - vt)$

但v = 0时的固有长度：$L_0 = x_2 - x_1$
因此：$L = L_0/\gamma$ ∎

## 29.6 不变间隔

**定理 29.6**（时空距离）：
间隔在洛伦兹变换下不变：
$$ds^2 = -c^2dt^2 + dx^2 + dy^2 + dz^2 = ds'^2$$

*直接验证*：
$$ds'^2 = -c^2(\gamma dt - \gamma\beta dx/c)^2 + (\gamma dx - \gamma\beta c dt)^2 + dy^2 + dz^2$$

展开并简化：
$$ds'^2 = -c^2dt^2(1-\beta^2)\gamma^2 + dx^2(1-\beta^2)\gamma^2 + dy^2 + dz^2$$

由于$(1-\beta^2)\gamma^2 = 1$，我们得到$ds'^2 = ds^2$。∎

真实距离超越坐标！
