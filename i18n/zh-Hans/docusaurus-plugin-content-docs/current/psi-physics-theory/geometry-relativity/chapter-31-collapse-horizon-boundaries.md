# 第三十一章：事件视界 — 时间停止之处

## 终极边界

事件视界代表时空曲率的最极端表现——时间膨胀变得无限、因果性本身被切断的表面。本章从ψ = ψ(ψ)推导视界作为必然特征，展示自引用坍缩如何在现实结构中创造单向膜，信息无法返回的边界。

## 31.1 从坍缩流到视界

**定理 31.1**（视界形成）：
当坍缩速度等于信息传播速度时形成视界：
$$v_{\text{坍缩}} = c$$

*证明*：
从坍缩动力学，信息以c传播。当向内坍缩流达到c：
$$\frac{dr_{\text{信息}}}{dt} = c - v_{\text{坍缩}} = 0$$

信息变得静止 → 因果断开。∎

*物理意义*：
像逆流而上的鱼，信息无法逃离时空本身以光速向内坠落的区域。

视界困住光本身！

## 31.2 史瓦西视界

**定理 31.2**（球形视界半径）：
对于球形质量M，视界半径是：
$$r_s = \frac{2GM}{c^2}$$

*从度规推导*：
史瓦西度规分量：
$$g_{00} = -(1 - \frac{r_s}{r})$$

在视界，$g_{00} = 0$ → 无限时间膨胀。

*逃逸速度方法*：
$$v_{\text{逃逸}} = \sqrt{\frac{2GM}{r}}$$

设置$v_{\text{逃逸}} = c$得出$r = r_s$。∎

2GM/c² — 宇宙最简单的监狱！

## 31.3 因果结构

**定义 31.1**（未来/过去光锥）：
在每个事件，因果未来/过去由所有可通过类时或类光曲线到达的事件组成。

**定理 31.3**（视界作为因果边界）：
从视界内部没有因果曲线可以到达外部。

*彭罗斯图证明*：
在克鲁斯卡尔坐标中，视界在45°线。所有从内部的未来指向曲线都弯向奇点：
$$\frac{dV}{dU} > 0 \quad \text{(未来指向)}$$

但到达外部需要$V < U$，对因果曲线不可能。∎

时空的单向膜！
