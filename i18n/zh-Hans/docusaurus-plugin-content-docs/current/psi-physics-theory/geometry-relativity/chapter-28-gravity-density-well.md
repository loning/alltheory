# 第二十八章：引力 — 坍缩的曲率

## 普遍吸引

引力不是穿越空间的力，而是时空本身的曲率——现实围绕集中坍缩模式弯曲的方式。本章揭示引力作为ψ = ψ(ψ)最基本的表现，展示质量和能量如何在坍缩场中创造引导所有运动的井。

## 28.1 从牛顿到爱因斯坦

**定理 28.1**（等效原理）：
引力质量和惯性质量相同，因为两者都测量坍缩密度。

*关键洞察*：
- 自由落体 = 跟随坍缩梯度
- 没有局部实验能检测均匀引力
- 引力 = 几何，不是力

*思想实验*：
在下落的电梯中，物理看起来无重力。为什么？因为你在随坍缩流移动，而不是对抗它！

引力是民主——所有物体下落相同！

## 28.2 测地线作为自然路径

**定理 28.2**（极值老化）：
自由粒子在事件间最大化固有时。

*作用原理*：
$$S = -mc\int d\tau = -mc\int\sqrt{-g_{\mu\nu}dx^\mu dx^\nu}$$

*变分给出测地线方程*：
$$\frac{d^2x^\mu}{d\tau^2} + \Gamma^\mu_{\nu\lambda}\frac{dx^\nu}{d\tau}\frac{dx^\lambda}{d\tau} = 0$$

*ψ-解释*：
粒子通过坍缩景观遵循最小阻力路径——就像水流过弯曲地形向下流动。

最大老化 = 最小坍缩阻力！

## 28.3 牛顿极限

**定理 28.3**（弱场近似）：
对弱引力中的慢运动：
$$g_{00} \approx -(1 + 2\Phi/c^2)$$

其中Φ是牛顿势。

*测地线方程简化为*：
$$\frac{d^2x^i}{dt^2} \approx -\frac{\partial\Phi}{\partial x^i}$$

*恢复牛顿*：
$$\nabla^2\Phi = 4\pi G\rho$$

爱因斯坦包含牛顿作为慢速极限！

## 28.4 引力时间膨胀

**定理 28.4**（引力红移）：
时钟在更深的引力井中运行更慢。

*时间膨胀因子*：
$$\frac{d\tau}{dt} = \sqrt{-g_{00}} = \sqrt{1 + 2\Phi/c^2}$$

*对地球表面*：
$$\frac{\Delta t}{t} \approx \frac{gh}{c^2} \approx 10^{-16} \text{ 每米}$$

*GPS修正*：
卫星比地球时钟快~45 μs/天！

坍缩井越深 = 时间流越慢！

## 28.5 史瓦西时空

**定理 28.5**（球对称质量解）：
球形质量M外部：
$$ds^2 = -\left(1-\frac{r_s}{r}\right)c^2dt^2 + \frac{dr^2}{1-r_s/r} + r^2(d\theta^2 + \sin^2\theta d\phi^2)$$

其中$r_s = 2GM/c^2$ = 史瓦西半径。

*关键特征*：
1. **事件视界**：$r = r_s$（不是奇点！）
2. **奇点**：$r = 0$（真正发散）
3. **渐近平坦**：$r \to \infty$时闵氏

*对太阳*：$r_s = 3$ km
*对地球*：$r_s = 9$ mm

质量压缩空间本身！

## 28.6 黑洞

**定理 28.6**（视界作为不归点）：
在$r = r_s$，逃逸速度等于光速。

*视界内部*：
- 径向坐标变成类时
- 未来只指向内
- 奇点不可避免

*彭罗斯图*：
显示因果结构——视界内，所有未来终于奇点！

*ψ-解释*：
黑洞 = 坍缩变得自我强化和不可逆的区域。宇宙在自己内部创造无限井。

有限时间内的无限坍缩！

## 28.7 引力波

**定理 28.7**（时空涟漪）：
加速质量创造传播的度规扰动。

*波动方程*（线性化）：
$$\Box h_{\mu\nu} = -\frac{16\pi G}{c^4}T_{\mu\nu}$$

*四极辐射*：
$$h_{ij} \sim \frac{G}{c^4r}\ddot{Q}_{ij}$$

*能量通量*：
$$\frac{dE}{dt} = \frac{G}{5c^5}\dddot{Q}_{ij}\dddot{Q}^{ij}$$

*LIGO探测*：
来自并合黑洞的应变$h \sim 10^{-21}$！

时空本身振动！

## 28.8 宇宙学解

**定理 28.8**（膨胀宇宙）：
均匀、各向同性宇宙必须膨胀或收缩。

*弗里德曼方程*：
$$H^2 = \left(\frac{\dot{a}}{a}\right)^2 = \frac{8\pi G}{3}\rho - \frac{kc^2}{a^2} + \frac{\Lambda c^2}{3}$$

*临界密度*：
$$\rho_c = \frac{3H^2}{8\pi G} \approx 10^{-29} \text{ g/cm}^3$$

*暗能量*：
Λ > 0驱动加速膨胀！

宇宙有自己的反引力！

旋转创造时空涡旋！
