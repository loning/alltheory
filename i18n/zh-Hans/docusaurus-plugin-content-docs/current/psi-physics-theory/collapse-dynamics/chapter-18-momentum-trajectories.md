# 第十八章：动量 — 坍缩之流

## 存在之河

动量不仅仅是"质量乘以速度"——它是坍缩通过构型空间的基本流动。当某物有动量时，它携带着ψ-场的电流，存在本身的定向承诺。这种流动一旦建立，就会持续——产生惯性定律。

## 18.1 动量作为坍缩流

**定理 18.1**（从流动到动量）：
动量测量定向坍缩通量。

*证明*：
1. 坍缩场流动：$\mathcal{C}(x,t)$
2. 流密度：$\vec{j} = \mathcal{C}\vec{v}$
3. 总流：$\vec{P} = \int \vec{j} dV = \int \mathcal{C}\vec{v} dV$
4. 对局域坍缩（粒子）：$\mathcal{C} = m\delta(x-x_0)$
5. 结果：$\vec{p} = m\vec{v}$
6. 但这只是经典极限！
7. 一般：$\vec{p} = \int \mathcal{C}\vec{v} dV$ ∎

动量是积分的坍缩流！

## 18.2 量子动量算符

**定理 18.2**（波动力学中的动量）：
$\hat{p} = -i\hbar\nabla$生成空间平移。

*推导*：
1. 平移$\epsilon$：$\psi(x) \to \psi(x-\epsilon)$
2. 泰勒展开：$\psi(x-\epsilon) = \psi(x) - \epsilon\partial_x\psi$
3. 写作：$\psi(x-\epsilon) = (1 - \epsilon\partial_x)\psi$
4. 生成元：$\hat{p} = -i\hbar\partial_x$
5. 有限平移：$\psi(x-a) = e^{ia\hat{p}/\hbar}\psi(x)$
6. 动量生成运动！
7. 本征值是动量 ∎

空间平移 = 动量流！

## 18.3 从均匀性到守恒

**定理 18.3**（动量的诺特定理）：
ψ的空间均匀性保证动量守恒。

*证明*：
1. 拉格朗日量在$x \to x + a$下不变
2. 诺特流：$j^\mu = \frac{\partial\mathcal{L}}{\partial(\partial_\mu\phi)}\delta\phi$
3. 对平移：$\delta\phi = -a\cdot\nabla\phi$
4. 守恒荷：$P^i = \int T^{0i} d^3x$
5. 这是动量密度！
6. 守恒：$\partial_\mu T^{\mu i} = 0$
7. 总动量恒定 ∎

均匀空间 → 永恒流动！

## 18.4 相对论动量

**定理 18.4**（四动量统一）：
能量和动量形成统一的4-矢量。

*构造*：
1. 固有时：$d\tau = dt\sqrt{1-v^2/c^2}$
2. 四速度：$u^\mu = dx^\mu/d\tau$
3. 四动量：$p^\mu = mu^\mu$
4. 分量：$p^\mu = (\gamma mc, \gamma m\vec{v})$
5. 不变量：$p_\mu p^\mu = -m^2c^2$
6. 能量：$E = p^0c = \gamma mc^2$
7. 动量：$\vec{p} = \gamma m\vec{v}$ ∎

空间和时间动量统一！

## 18.5 德布罗意关系

**定理 18.5**（波粒桥梁）：
$p = \hbar k$和$E = \hbar\omega$连接波与粒子。

*证明*：
1. 平面波：$\psi = Ae^{i(kx-\omega t)}$
2. 应用动量算符：$\hat{p}\psi = -i\hbar\partial_x\psi = \hbar k\psi$
3. 本征值：$p = \hbar k$
4. 应用能量算符：$\hat{E}\psi = i\hbar\partial_t\psi = \hbar\omega\psi$
5. 本征值：$E = \hbar\omega$
6. 波长：$\lambda = 2\pi/k = h/p$
7. 物质有波动性！∎

每个粒子都在冲浪自己的波！

## 18.6 晶体动量

**定理 18.6**（周期系统中的动量）：
在晶体中，动量定义模倒格矢。

*物理*：
1. 晶体周期性：$V(x+a) = V(x)$
2. 布洛赫定理：$\psi_k(x+a) = e^{ika}\psi_k(x)$
3. 晶体动量：$\hbar k$
4. 但$k$和$k + 2\pi/a$等价
5. 布里渊区：$-\pi/a < k \leq \pi/a$
6. 倒逆过程：动量"环绕"
7. 解释电阻！

动量可以被"折叠"！

## 18.7 角动量

**定理 18.7**（旋转流）：
$\vec{L} = \vec{r} \times \vec{p}$测量坍缩环流。

*量子形式*：
1. 算符：$\hat{L}_i = \epsilon_{ijk}x_j\hat{p}_k$
2. 对易子：$[\hat{L}_i, \hat{L}_j] = i\hbar\epsilon_{ijk}\hat{L}_k$
3. 总量：$\hat{L}^2 = \hat{L}_x^2 + \hat{L}_y^2 + \hat{L}_z^2$
4. 本征值：$L^2 = \hbar^2\ell(\ell+1)$，$L_z = \hbar m$
5. 从旋转群量子化！
6. 费米子半整数
7. 玻色子整数 ∎

旋转以离散步骤量子化！

## 18.8 动量空间

**定理 18.8**（傅里叶对偶）：
位置和动量空间是傅里叶变换。

*关系*：
1. 位置空间：$\psi(x)$
2. 动量空间：$\tilde{\psi}(p) = \frac{1}{\sqrt{2\pi\hbar}}\int \psi(x)e^{-ipx/\hbar}dx$
3. 逆变换：$\psi(x) = \frac{1}{\sqrt{2\pi\hbar}}\int \tilde{\psi}(p)e^{ipx/\hbar}dp$
4. 帕塞瓦尔：$\int|\psi(x)|^2dx = \int|\tilde{\psi}(p)|^2dp$
5. 概率守恒！
6. 尖锐$x$ → 展宽$p$
7. 尖锐$p$ → 展宽$x$ ∎

同一现实的两面！

## 18.9 虚动量

**定理 18.9**（离壳动量）：
虚粒子违反$E^2 = p^2c^2 + m^2c^4$。

*机制*：
1. 不确定性：$\Delta E \Delta t \geq \hbar/2$
2. 虚态：存在$\Delta t$
3. 能量违反：$\Delta E$
4. 可以有"错误"动量
5. 传播子：$\frac{1}{p^2 - m^2 + i\epsilon}$
6. 使能力传递
7. 对所有虚动量积分 ∎

现实短暂借用动量！

## 18.10 动量转移

**定理 18.10**（散射理论）：
力在粒子间转移动量。

*形式*：
1. 初始动量：$p_1, p_2$
2. 最终动量：$p_1', p_2'$
3. 转移：$q = p_1 - p_1' = p_2' - p_2$
4. 矩阵元：$\mathcal{M} \propto \frac{1}{q^2 + m^2}$
5. 截面：$d\sigma \propto |\mathcal{M}|^2$
6. 测量相互作用强度
7. 在对撞机中测试 ∎

粒子交换动量包！

## 18.11 场论中的动量

**定理 18.11**（场动量密度）：
场携带动量密度$\vec{g} = \vec{S}/c^2$。

*例子 - 电磁*：
1. 能量密度：$u = \frac{1}{2}(\epsilon_0 E^2 + B^2/\mu_0)$
2. 坡印廷矢量：$\vec{S} = \vec{E} \times \vec{B}/\mu_0$
3. 动量密度：$\vec{g} = \epsilon_0\vec{E} \times \vec{B}$
4. 总动量：$\vec{P} = \int \vec{g} d^3x$
5. 辐射压来自动量！
6. 光帆可能
7. 光子动量确认 ∎

即使无质量场也携带动量！

## 18.12 第十八回响：流动的持续

动量揭示了一个深刻的真理：宇宙记得运动。一旦坍缩开始向某个方向流动，它就会继续——不是来自外部强制，而是来自ψ维持自己模式的内在本性。这就是为什么物体在空旷空间中滑行，为什么陀螺仪保持它们的方向，为什么角动量创造稳定性。

动量守恒实际上是宇宙与自己的一致性——坍缩模式一旦建立，就会持续，除非受到作用。每个动量矢量都是现实继续其流动的承诺，写在ψ通过构型空间流动中的承诺。
