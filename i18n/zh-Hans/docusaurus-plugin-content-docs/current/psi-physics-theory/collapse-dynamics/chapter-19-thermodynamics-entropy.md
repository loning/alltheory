# 第19章：塌缩热力学与熵

## 衰变之箭

为什么时间有方向？为什么无序增加？为什么我们不能让打碎的鸡蛋复原？本章揭示熵不是无序而是塌缩多重性——ψ折叠到自身同时看起来相同的方式数。

## 19.1 熵作为塌缩计数

**经典**：S = k ln Ω（玻尔兹曼）
**信息**：S = -∑ pᵢ ln pᵢ（香农）
**ψ-定义**：S = k ln N_collapse

**定义19.1**（塌缩熵）：
$$\boxed{S = k_B \ln |\{\mathcal{C}_i : \mathcal{O}(\mathcal{C}_i) = \mathcal{O}_0\}|}$$

给出相同可观测量的塌缩态数的对数。

## 19.2 第二定律

**定理19.1**（熵增）：
在孤立系统中，S永不减少。

*证明*：
塌缩分叉是不可逆的（第15章）。
每次分叉：N → N' ≥ N 个可能态。
因此：S' = k ln N' ≥ k ln N = S
熵增加！∎

**ψ-洞察**：时间之箭是塌缩之箭——指向更多可能性。

## 19.3 温度作为塌缩梯度

**定义19.2**（温度）：
$$\frac{1}{T} = \left(\frac{\partial S}{\partial E}\right)_V$$

**ψ-含义**：温度度量新塌缩模式随能量变得可用的速度。

**热**：每能量单位有许多模式
**冷**：每能量单位有少量模式
**零度**：没有新模式（第三定律）

## 19.4 麦克斯韦妖

**悖论**：妖精分选分子，减少熵？

**解决**：妖精必须：
1. 测量分子速度（信息）
2. 存储/擦除信息
3. 擦除增加熵：ΔS ≥ k ln 2

**更深真理**：信息是物理的——知晓需要塌缩分叉。

## 19.5 黑洞熵

**贝肯斯坦-霍金**：
$$S_{BH} = \frac{k_B c³ A}{4G\hbar}$$

熵正比于面积，而非体积！

**ψ-解释**：黑洞最大化塌缩密度。表面积计数可区分的塌缩终点——内部态是等价的。

## 19.6 纠缠熵

**对于量子系统**：
$$S_A = -\text{Tr}(\rho_A \ln \rho_A)$$

**联系**：纠缠熵度量子系统间的塌缩关联。

**面积定律**：S ∝ 面积（非体积）对于基态——与全息原理的深刻联系。

## 19.7 自由能

**定义19.3**（亥姆霍兹自由能）：
$$F = E - TS$$

**ψ-诠释**：F度量有用的塌缩势——能量减去已经分散的塌缩模式。

**平衡**：系统最小化F，平衡能量和熵。

## 19.8 相变

**在临界点**：
- 序参量消失
- 关联发散
- 对称性改变

**ψ-观点**：当塌缩模式经历定性重组时发生相变——如水分子突然锁定成冰晶。

## 19.9 涨落定理

**超越平衡**：
$$P(\Delta S = -\sigma) / P(\Delta S = +\sigma) = e^{-\sigma/k}$$

熵可以减少，但指数级不可能。

**ψ-现实**：塌缩偶尔局部反转，同时全局增加。

## 19.10 量子热力学

**悖论**：纯态有S = 0，但感觉热？

**解决**：与环境的纠缠创造有效温度：
$$\rho_{system} = \text{Tr}_{env}|\Psi\rangle\langle\Psi|$$

约化密度矩阵即使来自纯全局态也有熵。

## 19.11 实践练习

**练习19.1**：计算自由膨胀中的熵变。

**练习19.2**：从塌缩约束推导卡诺效率。

**练习19.3**：说明为什么永动机违反塌缩不可逆性。

**练习19.4**：计算贝尔态的纠缠熵。

## 19.12 章节总结

熵不是无序而是可能性——产生相同观测的塌缩路径的多重性。第二定律表明塌缩自然地随时间探索更多可能性。温度、自由能和相变都从自指涉塌缩的统计中浮现。时间之箭指向最大塌缩多重性。

**第19回音**：在熵中，ψ计数自己的反射——发现一个可观测量掩盖无数内部态，衰变实际上是可能性空间中的增长，死亡是从外部观看的生命。
