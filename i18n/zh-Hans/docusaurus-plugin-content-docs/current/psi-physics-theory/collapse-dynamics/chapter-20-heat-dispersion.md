# 第20章：热作为塌缩分散

## 能量的民主

热——能量最民主的形式，在所有可用模式间平等分散。但热到底是什么？本章揭示热能作为分散的塌缩，已经忘记其起源并探索所有可能路径的能量。

## 20.1 热与功

**功**：定向塌缩流
**热**：随机化塌缩分散

**定义20.1**（热塌缩）：
$$\boxed{Q = \sum_i \epsilon_i \delta n_i}$$

其中 εᵢ 是模式能量，δnᵢ 是占据数变化。

**关键差别**：功可以完全转换为其他形式；热不能（第二定律）。

## 20.2 微观起源

**经典图像**：分子动能
**ψ-图像**：所有模式上的塌缩激发

**定理20.1**（能均分）：
每个二次自由度：⟨E⟩ = kᴉT/2

*证明*：
对于谐振模式：$E = \frac{1}{2}kx²$
$$\langle E \rangle = \frac{\int E e^{-E/k_BT} dE}{\int e^{-E/k_BT} dE} = \frac{k_BT}{2}$$

能量民主分布！∎

## 20.3 热容

**定义20.2**（分散容量）：
$$C = \frac{dQ}{dT} = T\frac{dS}{dT}$$

**量子效应**：
- 低温：C → 0（第三定律）
- 高温：C → 经典值
- 过渡在 T ~ ℏω/kᴉ

**ψ-洞察**：热容度量有多少塌缩模式随温度激活。

## 20.4 热传导

**傅里叶定律**：
$$\vec{j}_Q = -\kappa \nabla T$$

**机制**：
1. **金属**：电子塌缩波携带热
2. **绝缘体**：声子（晶格塌缩）传播
3. **辐射**：光子塌缩传递

**普适性**：都涉及塌缩模式从热（多模式）向冷（少模式）传播。

## 20.5 热辐射

**普朗克定律**：
$$u(\nu, T) = \frac{8\pi h\nu³}{c³} \frac{1}{e^{h\nu/k_BT} - 1}$$

**ψ-推导**：
腔中的电磁塌缩模式。
每个模式：平均占据数 $\langle n \rangle = 1/(e^{\hbar\omega/k_BT} - 1)$
对模式求和得到普朗克分布。

**斯特藩-玻尔兹曼**：总辐射功率 ∝ T⁴

## 20.6 相空间流

**刘维尔定理**：相空间体积守恒。

**热产生**：不是创造体积而是扩散到更多维度：
```
有序 → 无序
|||||||    ..:..::
|||||||    ::...:.  
(窄)       (展开)
```

**ψ-图像**：热是塌缩探索配置空间。

## 20.7 热涨落

**爱因斯坦洞察**：布朗运动来自热撞击。

**涨落大小**：
$$\langle (\Delta E)² \rangle = k_BT² C$$

**含义**：即使平衡也嗡鸣着塌缩涨落。温度设定涨落尺度。

## 20.8 量子热

**零点运动**：T = 0 仍有能量！
$$E_0 = \frac{\hbar\omega}{2}$$

**量子热容**：
$$C_V = 3Nk_B \left(\frac{\Theta_D}{T}\right)^3 \int_0^{\Theta_D/T} \frac{x⁴ e^x}{(e^x - 1)²} dx$$

（固体的德拜模型）

## 20.9 信息与热

**兰道尔原理**：擦除一比特释放热：
$$Q_{min} = k_BT \ln 2$$

**ψ-联系**：信息擦除需要塌缩分叉合并，必然在别处增加熵。

## 20.10 热寂

**宇宙的命运？**：最大熵态——均匀温度，无梯度。

**但是**：引力创造负热容！
热的更热，冷的更冷。
热寂可能不可能。

## 20.12 章节总结

热是迷失方向的能量——分散在所有可用模式上的塌缩。与定向的功不同，热代表民主能量，在可能性间平等共享。从分子振动到宇宙背景辐射，热显现ψ探索所有路径的倾向。温度梯度驱动宇宙的引擎，而热平衡代表静止的塌缩。

**第20回音**：在热中，ψ发现公平——能量不按功绩而按可能性分配，教导我们最终，所有路径在熵的眼中都是平等的。
