# 第二十二章：功 — 有组织坍缩的收获

## 定向流

功代表能量最有组织的形式——定向的、相干的、有目的的。不像热的民主传播，功将坍缩能量沿特定路径引导以实现特定目标。本章揭示机械功如何从协调的坍缩位移中涌现。

## 22.1 功作为路径积分

**定理 22.1**（机械功）：
功是力沿位移路径的积分。
$$W = \int_C \vec{F} \cdot d\vec{r}$$

*ψ-解释*：
1. 力 = 坍缩梯度（第17章）
2. 位移 = 坍缩轨迹移动
3. 功 = 累积的坍缩势变化
4. 非保守力路径相关
5. 保守力路径无关
6. 测量有组织的能量传递
7. 可以完全转换为其他形式 ∎

功收获定向坍缩流！

## 22.2 保守与耗散

**定理 22.2**（功的分类）：
保守功 ↔ 势能；耗散 → 热。

*保守判据*：
$$\oint_C \vec{F} \cdot d\vec{r} = 0$$
$$\nabla \times \vec{F} = 0$$
$$F = -\nabla U$$

*例子*：
- 重力：举升储存势能
- 弹簧：压缩储存弹性能
- 电场：电荷分离储存场能

*耗散*：
- 摩擦 → 随机分子运动
- 粘滞 → 流体湍流
- 电阻 → 焦耳热

组织性决定功的命运！

## 22.3 热力学功

**定理 22.3**（PV功）：
气体膨胀功：$W = -\int P dV$

*微观视角*：
1. 分子以平均力撞击活塞
2. 活塞移动 → 体积增加
3. 每次碰撞传递动量
4. 净效应：有组织的位移
5. 系统做功（W < 0）
6. 内能减少
7. 除非同时加热 ∎

压力驱动有组织的膨胀！

## 22.4 第一定律

**定理 22.4**（能量守恒）：
$dU = \delta Q - \delta W$

*深刻含义*：
- U：总内部坍缩能量
- Q：无组织能量传递
- W：有组织能量传递
- 能量形式可以改变
- 总量守恒
- 功和热可互换
- 但有限制（第二定律）

能量重塑但永不消失！

## 22.5 可用功

**定理 22.5**（㶲/可用性）：
从态到平衡的最大有用功：
$$W_{max} = U - U_0 - T_0(S - S_0) + P_0(V - V_0)$$

*关键洞察*：
- 不是所有能量都能变成功
- 熵限制可用性
- 环境设定基线
- 㶲 = 有用能量
- 总是少于总能量

宇宙对所有功提取征税！

## 22.6 虚功原理

**定理 22.6**（平衡条件）：
如果对所有虚位移$\delta W = 0$，系统处于平衡。

*数学形式*：
$$\delta W = \sum_i \vec{F}_i \cdot \delta\vec{r}_i = 0$$

*应用*：
- 静力学：力平衡
- 动力学：达朗贝尔原理
- 拉格朗日力学基础
- 揭示约束力

平衡 = 小扰动无功！

## 22.7 功率与强度

**定义**：功率 = 功率
$$P = \frac{dW}{dt} = \vec{F} \cdot \vec{v}$$

*瞬时功率*：
- 机械：$P = \tau\omega$（扭矩×角速度）
- 电学：$P = IV$（电流×电压）
- 波：$P = \frac{1}{2}\omega^2A^2\rho c$（强度）

*极限*：
- 生物：~400 W持续（人类）
- 技术：GW（发电厂）
- 天体物理：10^26 W（太阳输出）

功率测量坍缩组织率！

## 22.8 量子功

**定理 22.7**（量子力学中的功）：
对时变哈密顿量：
$$W = \int_0^t \left\langle \frac{\partial H}{\partial t'} \right\rangle dt'$$

*特殊性*：
1. 无经典轨迹
2. 功量子力学涨落
3. 测量影响做功
4. 零点运动贡献
5. 量子摩擦可能

功变成概率性的！

## 22.9 信息功

**定理 22.8**（兰道尔-贝内特）：
计算需要最小功：
$$W \geq k_BT \ln 2 \text{ 每擦除一比特}$$

*可逆计算*：
- 理论上零能量
- 实际上困难
- 时间-能量权衡
- 量子计算优势

信息处理是物理功！

## 22.10 生物功

**生命的引擎**：
1. **ATP水解**：-30.5 kJ/mol
   - 通用能量货币
   - 偶联反应
   
2. **分子马达**：
   - 驱动蛋白：8 nm步长
   - 效率 > 50%
   - 整流布朗运动

3. **光合作用**：
   - 光 → 化学功
   - 量子相干辅助
   - 某些地方接近单位效率

生命掌握纳米尺度功提取！

## 22.11 宇宙学功

**定理 22.9**（膨胀宇宙）：
宇宙膨胀对物质做功：
$$W = -\int P dV = -\frac{4\pi}{3}P(R_f^3 - R_i^3)$$

*结果*：
- 光子红移（失去能量）
- 物质冷却
- 暗能量做负功
- 总能量不守恒！
- 广义相对论允许能量不守恒

宇宙对自己做功！

## 22.12 第二十二回响：目的的架构

功揭示了宇宙有组织行动的能力——将随机热运动引导成定向成就的能力。从沿细胞高速公路行走的分子马达到将蒸汽转换为电力的巨大涡轮，功代表为目的而驾驭的坍缩模式。

功与热之间、组织与混沌之间的相互作用驱动所有过程。生命本身可以被看作是一个复杂的功提取机器，通过对抗熵潮做功来维持组织。在功中，我们发现ψ的创造性方面——不只是流动而是建造，不只是分散而是成就。
