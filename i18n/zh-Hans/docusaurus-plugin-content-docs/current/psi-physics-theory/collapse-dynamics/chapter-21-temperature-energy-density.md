# 第21章：温度作为塌缩能量密度

## 存在的强度

温度——我们感受为热或冷，但它测量什么？本章揭示温度作为塌缩能量的密度，ψ在其自指涉之舞中振动的强度。

## 21.1 定义温度

**操作性**：温度计测量的东西
**统计性**：每个模式的平均动能
**ψ-定义**：每个可及态的塌缩能量

**定义21.1**（基本温度）：
$$\boxed{\frac{1}{k_BT} = \frac{\partial \ln \Omega}{\partial E}}$$

其中 Ω 是可及塌缩态数。

## 21.2 温度的深层含义

**定理21.1**（温度普适性）：
热接触的系统达到相同温度。

*证明*：
对于固定总能量的最大熵：
$$\frac{\partial S_1}{\partial E_1} = \frac{\partial S_2}{\partial E_2}$$

因为 $\partial S/\partial E = 1/T$：
$$T_1 = T_2$$

温度均衡！∎

**ψ-洞察**：温度是塌缩的共同货币。

## 21.3 绝对零度

**第三定律**：T → 0 时 S → 0

**不可能性**：不能在有限步骤内达到 T = 0。

**ψ-原因**：零温度意味着单一塌缩态。但测量需要分叉，创造熵。验证的行为阻止了实现。

## 21.4 负温度

**可能吗？**是的，在有界能量系统中！

**例子**：具有最大能量的自旋系统
$$T < 0 \text{ 当 } \partial S/\partial E < 0$$

**奇怪性质**：负T比正T"更热"——能量从负流向正。

**ψ-理解**：倒置的塌缩布居——更多系统处于高能态。

## 21.5 温度尺度

**自然尺度**：普朗克温度
$$T_P = \sqrt{\frac{\hbar c^5}{G k_B^2}} \approx 10^{32} K$$

**意义**：量子引力主导时的温度——塌缩处于最基本状态。

**可观测范围**：
- CMB：2.7 K（宇宙当前温度）
- 太阳核心：10⁷ K
- LHC碰撞：10¹³ K
- 玻色-爱因斯坦凝聚：10⁻⁹ K

## 21.6 量子温度

**德布罗意波长**：
$$\lambda_{thermal} = \frac{h}{\sqrt{2\pi m k_B T}}$$

**量子区域**：当 λ_thermal > 粒子间距

**效应**：
- 玻色-爱因斯坦凝聚
- 费米简并
- 量子相变

## 21.7 温度与时间

**虚时间**：τ = it

**热场论**：
$$\langle \mathcal{O} \rangle_T = \text{Tr}[e^{-\beta H} \mathcal{O}]/Z$$

其中 β = 1/kᴉT。

**深层联系**：温度是虚时间周期！热物理是欧几里得量子力学。

## 21.8 霍金温度

**黑洞辐射**：
$$T_H = \frac{\hbar c^3}{8\pi G M k_B}$$

**ψ-机制**：塌缩视界创造粒子对。一个落入，一个逃逸，带走能量。

**悖论**：黑洞有温度但也有最大熵——它们是热的却是纯塌缩！

## 21.9 温度梯度

**驱动一切**：
- 天气：太阳加热创造压力差
- 生命：温度梯度使代谢成为可能
- 恒星：核心-表面梯度驱动聚变
- 宇宙：CMB各向异性播种结构

**ψ-原理**：梯度是寻求平衡的塌缩流。

## 21.10 有效温度

**非平衡系统**：能分配温度吗？

**例子**：
- 湍流：涡旋的"温度"
- 玻璃：虚拟温度
- 颗粒物质：动力学温度

**判据**：如果涨落-耗散定理成立：
$$\langle x(t)x(0) \rangle = k_BT \chi(t)$$

则有效温度有意义。
