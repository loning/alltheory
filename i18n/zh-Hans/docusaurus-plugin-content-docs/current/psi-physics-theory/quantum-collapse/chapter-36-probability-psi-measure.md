# 第36章：塌缩概率与 ψ 测度

## 波恩规则的推导

为什么量子概率由 |ψ|² 给出？这个看似任意的规则——测量到态 |n⟩ 的概率等于 |⟨n|ψ⟩|²——或许是量子力学最神秘的公设。在 ψ 物理学中，波恩规则不是公设而是定理：概率测量 ψ 空间中塌缩结果的相对密度。

## 36.1 概率问题

**标准量子力学**：波恩规则被公设为：
$$P(n) = |\langle n|\psi\rangle|^2$$

**ψ 物理学**：波恩规则从塌缩测度理论推导而来。

**关键洞察**：概率 = 不完全态解析时塌缩结果的相对频率。

## 36.2 塌缩测度理论

**定义 36.1**（ψ 测度）：
对于态 $|\psi\rangle = \sum_n \alpha_n |n\rangle$，定义测度：
$$\mu_\psi(S) = \sum_{n \in S} |\alpha_n|^2$$

对于结果的任意子集 S。

**解释**：μ_ψ 测量导向 S 中结果的塌缩路径的"体积"。

## 36.3 推导波恩规则

**定理 36.1**（从测度推导波恩规则）：
结果 n 的概率等于 ψ 测度：
$$P(n) = \mu_\psi(\{n\}) = |\alpha_n|^2$$

*证明*：
1. 不完全塌缩探索所有潜在结果
2. 每个结果的"权重" = 振幅平方
3. 测量以与权重成比例的频率选择结果
4. 归一化确保概率和为 1
因此：P(n) = |α_n|²/Σ|α_k|² = |α_n|²（对于归一化态）。∎

## 36.4 为什么是振幅平方？

**深层问题**：为什么是 |α|² 而不是 |α| 或 |α|⁴？

**ψ 答案**：振幅平方测量塌缩关联：
$$|\alpha_n|^2 = \langle\psi_n|\psi_n\rangle_{\mathcal{C}}$$

这表示潜在塌缩与实际结果之间的"重叠"——塌缩空间中的自然内积。

## 36.5 复振幅的必要性

**实振幅**：会给出概率 |α|²，与复振幅相同。

**为什么要复数？**干涉！只有复振幅允许：
$$|\alpha_1 + \alpha_2|^2 = |\alpha_1|^2 + |\alpha_2|^2 + 2\text{Re}(\alpha_1^*\alpha_2)$$

交叉项使得相长/相消干涉成为可能——量子行为的本质。

## 36.6 多粒子系统

**对于纠缠态**：
$$|\psi\rangle = \sum_{i,j} \alpha_{ij} |i\rangle_A \otimes |j\rangle_B$$

**联合概率**：
$$P(i,j) = |\alpha_{ij}|^2$$

**边缘概率**：
$$P_A(i) = \sum_j |\alpha_{ij}|^2$$

概率自然边缘化——无需额外假设。

## 36.7 连续变量

**位置本征态**：$\psi(x) = \langle x|\psi\rangle$

**概率密度**：
$$\rho(x) = |\psi(x)|^2$$

**ψ 解释**：ρ(x) 测量位置上的塌缩密度——不完全塌缩有多少"集中"在位置 x。

## 36.8 相位与概率

**全局相位**：$|\psi\rangle \rightarrow e^{i\phi}|\psi\rangle$

**对概率无影响**：
$$|e^{i\phi}\alpha_n|^2 = |\alpha_n|^2$$

**ψ 含义**：塌缩相空间中的全局旋转不改变塌缩密度——只有相对相位重要。

## 36.9 测量作为采样

**概念模型**：测量 = 从 ψ 测度随机采样

**类比**：
- 经典：从概率分布采样
- 量子：通过波恩规则从振幅分布采样

**关键区别**：量子采样改变态（塌缩），经典不会。

## 36.10 信息论联系

**香农熵**：$H = -\sum_n p_n \log p_n$

**冯·诺依曼熵**：$S = -\text{Tr}(\rho \log \rho)$

**ψ 统一**：两者都测量塌缩结果的不确定性：
- 香农：经典不确定性
- 冯·诺依曼：量子不确定性（包括相干性）

## 36.11 弱测量

**部分信息**：弱耦合测量给出：
$$\langle\hat{A}\rangle_{weak} = \frac{\text{Re}\langle\psi_f|\hat{A}|\psi_i\rangle}{\langle\psi_f|\psi_i\rangle}$$

**ψ 解释**：弱测量从塌缩转换振幅采样，而非最终态振幅。

## 36.12 量子概率 vs 经典概率

**经典**：概率反映无知
- "硬币有确定结果，我们只是不知道"

**量子**：概率是基础的
- "系统存在于叠加态直到被测量"

**ψ 统一**：两者都关于不完全信息，但量子包括不完全的现实。

## 36.13 多世界与概率

**埃弗雷特诠释**：所有结果在平行分支中发生。

**问题**：为什么我们观察到波恩规则频率？

**ψ 答案**：分支权重 = 塌缩测度。我们观察与我们分支的 ψ 测度成比例。

## 36.14 格里森定理

**定理 36.2**（格里森）：
量子态上的任何概率测度具有形式：
$$P(\Lambda) = \text{Tr}(\rho \Lambda)$$

对于某个密度算符 ρ 和 POVM 元素 Λ。

**结论**：波恩规则是与量子逻辑一致的唯一概率分配！

## 36.15 结论：概率作为塌缩地理

波恩规则从塌缩空间的几何自然涌现。概率不是任意分配而是不完全塌缩如何分布在潜在结果上的测度。|ψ|² 不是规则而是地图——显示每个量子系统在可能性景观中的哪里集中其实现的潜能。

这揭示了概率的量子本质：不仅是对预定结果的无知，而是在同时维持多重潜能的现实中的真正不确定性。当我们测量量子系统时，我们不是在揭示隐藏的性质，而是参与选择哪个潜能成为现实的塌缩过程。

波恩规则是 ψ 在决定前如何权衡其选项。振幅平方不仅测量可能性，还测量汇聚到每个结果的塌缩路径的字面密度。从这个意义上，量子力学与其说是关于预测，不如说是关于绘制潜能的地形——展示现实如何导航其自身可能性的空间。
