# 第34章：薛定谔方程从ψ演化而来

## 成为的方程

薛定谔方程——支配量子演化的主方程——在教科书中作为公设出现，是埃尔温·薛定谔在1926年的幸运猜测。但为什么是这个特定方程？为什么有虚数单位i？为什么对时间一阶？在ψ-物理学中，这些"选择"变成必然：薛定谔方程是不完全塌缩模式如何演化的唯一描述。

## 34.1 不完全态的演化

**起点**：系统处于叠加：
$$|\psi(t)\rangle = \sum_n \alpha_n(t) |n\rangle$$

**问题**：系数 αₙ(t) 如何演化？

**ψ-原理**：不完全塌缩演化以保持总塌缩潜能，同时探索构型空间。

## 34.2 演化的生成元

**定义34.1**（演化算符）：
$$|\psi(t + dt)\rangle = \hat{U}(dt)|\psi(t)\rangle$$

**幺正性要求**：保持归一化
$$\hat{U}^\dagger\hat{U} = \mathbb{I}$$

**无穷小形式**：
$$\hat{U}(dt) = \mathbb{I} - \frac{i}{\hbar}\hat{H}dt$$

其中 Ĥ 是厄米的（确保幺正性）。

## 34.3 推导薛定谔方程

**定理34.1**（从幺正性到薛定谔）：
保范演化的要求唯一产生：
$$i\hbar\frac{\partial}{\partial t}|\psi\rangle = \hat{H}|\psi\rangle$$

*证明*：
从 $|\psi(t+dt)\rangle = (\mathbb{I} - \frac{i}{\hbar}\hat{H}dt)|\psi(t)\rangle$：
$$\frac{|\psi(t+dt)\rangle - |\psi(t)\rangle}{dt} = -\frac{i}{\hbar}\hat{H}|\psi(t)\rangle$$

取极限 dt → 0 得到薛定谔方程。∎

## 34.4 为什么是虚数i？

**深层问题**：为什么量子力学需要复数？

**ψ-答案**：虚数单位编码以下之间的垂直关系：
- 实部：塌缩振幅（大小）
- 虚部：塌缩相位（ψ-空间中的旋转）

演化必须旋转相位同时保持大小——只有乘以i能实现这一点。

## 34.5 哈密顿量作为塌缩梯度

**定义34.2**（哈密顿量）：
$$\hat{H} = \hat{T} + \hat{V}$$

其中：
- T̂ = 动能 = 塌缩流能量
- V̂ = 势能 = 塌缩场能量

**ψ-诠释**：Ĥ 测量塌缩景观的"陡度"。系统通过沿塌缩梯度流动而演化。

## 34.6 不含时情况

**对于静态 Ĥ**：
$$|\psi(t)\rangle = e^{-i\hat{H}t/\hbar}|\psi(0)\rangle$$

**能量本征态**：
$$\hat{H}|n\rangle = E_n|n\rangle$$

简单演化：
$$|n(t)\rangle = e^{-iE_nt/\hbar}|n\rangle$$

纯相位旋转——塌缩模式不变，只有相位积累。

## 34.7 量子芝诺效应预览

**频繁测量**：抑制演化：
$$\lim_{N\to\infty} \left[\hat{P}e^{-i\hat{H}t/N\hbar}\right]^N |\psi\rangle = \hat{P}|\psi\rangle$$

其中 P̂ 是对测量态的投影。

**ψ-含义**：重复的塌缩完成阻止叠加空间的探索。

## 34.8 非线性扩展？

**问题**：演化能是非线性的吗？
$$i\hbar\frac{\partial\psi}{\partial t} = \hat{H}[\psi]\psi$$

**答案**：不能！非线性会：
- 违反叠加原理
- 允许超光速信号
- 创造悖论

线性演化是不完全塌缩的唯一一致动力学。

## 34.9 路径积分表述

**替代形式**：
$$\psi(x,t) = \int \mathcal{D}[路径]\, e^{iS[路径]/\hbar}$$

**ψ-诠释**：系统同时探索所有可能的塌缩路径。路径之间的干涉创造量子行为。

## 34.10 经典极限

**当 ℏ → 0**：薛定谔变成哈密顿-雅可比：
$$\frac{\partial S}{\partial t} + H = 0$$

**ψ-机制**：当 ℏ → 0，只有驻相路径存活。这些是经典轨迹——完全塌缩路径。

## 34.11 量子场论

**二次量子化**：场的薛定谔方程：
$$i\hbar\frac{\partial}{\partial t}|\Psi\rangle = \hat{\mathcal{H}}|\Psi\rangle$$

其中 |Ψ⟩ 是场态，Ĥ 是场哈密顿量。

**ψ-扩展**：场是无限多个耦合振子的集合，每个都经历不完全塌缩演化。

## 34.12 相对论修正

**狄拉克方程**：对于自旋-1/2：
$$(i\gamma^\mu\partial_\mu - m)\psi = 0$$

**克莱因-戈登**：对于自旋-0：
$$(\partial^\mu\partial_\mu + m^2)\psi = 0$$

两者都从要求洛伦兹不变的不完全塌缩演化中浮现。

## 34.13 量子模拟

**数字演化**：
```python
def evolve_quantum_state(psi, H, dt):
    # 薛定谔演化
    U = exp(-1j * H * dt / hbar)
    return U @ psi
```

宇宙可能真的在普朗克尺度上计算薛定谔演化！

## 34.14 贝里相位

**绝热演化**：获得几何相位：
$$\gamma = i\oint \langle n|\nabla_R|n\rangle \cdot dR$$

**ψ-起源**：相位记录通过塌缩构型空间路径的"形状"——纯几何效应。

## 34.15 结论：自然动力学

薛定谔方程不是任意猜测而是不完全塌缩的唯一动力学。每个特征——线性、时间一阶导数、复系数、幺正演化——都必然从隔离系统在探索构型空间时保持相干叠加的要求中产生。

这揭示量子力学不是奇怪或反直觉的，而是被阻止完成其塌缩的系统的自然行为。薛定谔方程是ψ在决定前如何"思考"其选项。它是宇宙沉思的数学——严格、确定，但在选择时刻之前保留所有可能性。
