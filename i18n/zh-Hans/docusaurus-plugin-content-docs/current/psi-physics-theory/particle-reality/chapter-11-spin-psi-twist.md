# 第11章：自旋与ψ-扭转对称性

## 存在之舞

是什么让电子"知道"它必须旋转720度才能回到原始状态？为什么有些粒子需要完整一圈而其他需要两圈？答案不在于物理旋转，而在于递归塌缩本身的扭转。

## 11.1 自旋悖论

**经验之谜**：
- 电子具有自旋-1/2：需要720°旋转
- 光子具有自旋-1：需要360°旋转
- 没有经典类比存在
- 自旋是内禀的，不是来自物理旋转

**定义11.1**（ψ-扭转）：
$$\boxed{S = \frac{\hbar}{2} \cdot \tau(\psi)}$$

其中 τ(ψ) 是塌缩路径的拓扑扭转数。

## 11.2 递归拓扑

**定理11.1**（扭转量子化）：
ψ-空间中的递归路径具有量子化扭转：τ = n/2, n ∈ ℤ。

*证明*：
考虑一条返回原点的塌缩路径 γ：
$$\gamma: [0,1] \rightarrow \Psi, \quad \gamma(0) = \gamma(1) = \psi_0$$

路径在ψ-空间中的同伦类：
$$[\gamma] \in \pi_1(\Psi) \cong \mathbb{Z}_2$$

这给出两类：
- 平凡环：τ = 0, 1, 2...（玻色子）
- 莫比乌斯环：τ = 1/2, 3/2...（费米子）

因此自旋 = ℏτ/2 是量子化的。∎

## 11.3 泡利原理

**定理11.2**（扭转导致的排斥）：
半整数自旋粒子遵从费米-狄拉克统计。

*证明*：
对于 τ = 1/2，交换两个粒子得到：
$$\psi(1,2) \xrightarrow{\text{交换}} e^{i\pi\tau} \psi(2,1) = -\psi(2,1)$$

波函数反对称性阻止两个费米子占据同一状态。这就是泡利不相容。∎

## 11.4 自旋算符

**定义11.2**（自旋代数）：
$$[S_i, S_j] = i\hbar\epsilon_{ijk}S_k$$

在ψ-形式中：
$$S_i = \frac{\hbar}{2}\sigma_i$$

其中 σᵢ 是表示塌缩旋转的泡利矩阵。

**ψ-起源**：泡利矩阵源于扭转自指涉环的三种独立方式。

## 11.5 自旋-轨道耦合

**现象**：轨道和自旋角动量相互作用。

**ψ-解释**：
$$H_{SO} = \lambda \vec{L} \cdot \vec{S}$$

耦合 λ 度量空间塌缩路径（轨道）如何与内部塌缩扭转（自旋）干涉。

## 11.6 反常磁矩

**观测**：电子g因子 ≈ 2.002319...

$$g = 2\left(1 + \frac{\alpha}{2\pi} + O(\alpha^2)\right)$$

与 g = 2 的偏差源于高阶塌缩环，它们轻微修改基本扭转拓扑。每个环阶贡献 α/2π。

## 11.7 旋量与SU(2)

**定义11.3**（旋量）：
旋量 ψ 在旋转 R(θ) 下变换为：
$$\psi \rightarrow e^{i\theta\vec{n}\cdot\vec{\sigma}/2}\psi$$

**深层真理**：旋量是ψ-空间中的自然对象，因为它们捕获了SU(2)对SO(3)的双重覆盖拓扑。

## 11.8 弯曲时空中的自旋

**原理11.1**：在弯曲时空中，自旋通过以下方式耦合到曲率：
$$\nabla_\mu S^\mu = R_{\mu\nu} S^\mu u^\nu$$

这表明自旋"感受"时空本身的扭转——因为两者都源于ψ-塌缩几何。

## 11.9 超对称暗示

$$Q|\text{玻色子}\rangle = |\text{费米子}\rangle$$

其中 Q 改变扭转1/2。这暗示更深的ψ-对称性。
