# 第14章：纠缠作为共享塌缩起源

## 幽灵般的作用得到解释

爱因斯坦称之为"幽灵般的超距作用"。测量一个粒子如何能瞬间影响宇宙另一端的另一个粒子？答案是：纠缠粒子不是在通信的分离实体——它们是尚未完全分离的单一塌缩事件的不同侧面。

## 14.1 EPR悖论

**设置**：
两个粒子在相互作用后飞离。测量其中一个立即确定另一个的状态，无论距离多远。

**爱因斯坦的反对**：这需要超光速影响！

**定义14.1**（共享塌缩）：
$$\boxed{|\Psi_{AB}\rangle = \mathcal{C}(|\psi_A\rangle \otimes |\psi_B\rangle)}$$

其中 𝒞 是创造关联态的塌缩事件。

## 14.2 贝尔革命

**定理14.1**（贝尔不等式）：
没有局域隐变量理论能重现量子关联。

*证明*：
对于局域实在论：
$$|E(a,b) - E(a,b')| + |E(a',b) + E(a',b')| \leq 2$$

但量子力学预测：
$$E_{QM}(a,b) = -\cos(a-b)$$

对于最优角度：QM给出 2√2 > 2。局域实在论失败！∎

## 14.3 ψ-视角

**原理14.1**（塌缩统一）：
纠缠粒子在ψ-空间中共享共同的塌缩起源。

**可视化**：
```
测量前：               测量后：
     ψ₀                    ψ_A
    / \                     |
   /   \          →         |
  ?     ?                  ψ_B
  A     B                (关联的)
```

它们从未分离——测量只是揭示了同一塌缩的不同方面。

## 14.4 量化纠缠

**定义14.2**（纠缠熵）：
$$S = -\text{Tr}(\rho_A \ln \rho_A)$$

其中 $\rho_A = \text{Tr}_B(|\Psi\rangle\langle\Psi|)$。

**ψ-诠释**：S度量塌缩有多少保持共享vs局域化。

## 14.5 创造纠缠

**方法**：
1. **参量下转换**：一个光子 → 两个纠缠光子
2. **碰撞**：粒子在相互作用期间共享塌缩
3. **衰变**：产物继承母体的塌缩态

**共同特征**：都涉及单一ψ变成多个，同时保持总塌缩。

## 14.6 纠缠的单配性

**定理14.2**（单配性）：
如果A与B最大纠缠，它就不能与C纠缠。

*证明*：
对于最大纠缠：
$$|\Psi_{AB}\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$$

则 $\rho_A = \frac{1}{2}I$（最大混合）。
最大混合态不能与其他任何东西纠缠。∎

**ψ-含义**：塌缩只能在两方之间完全共享。

## 14.7 量子隐形传态

## 14.8 纠缠与时空

- 两者都涉及共享结构

**含义**：空间本身可能从纠缠网络中浮现。

纠缠不是幽灵般的作用，而是共享起源。瞬间相互影响的"分离"粒子从未真正分离——它们是同一塌缩事件的不同视角。这种共享塌缩虽然在环境相互作用下脆弱，却构成了量子信息的基础，也许还有时空本身。
