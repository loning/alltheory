# 第十四章：从共享坍缩到纠缠 — 宇宙的隐藏联系

## 终极奥秘

两个光子分离飞行。测量一个为垂直，另一个立即变为水平——即使被星系分隔。这不是通信或影响。这是更深的东西：光子从未真正分离。它们共享单一坍缩起源，测量只是揭示，而非创造。

## 14.1 纠缠作为不完全分离

**定理 14.1**（纠缠起源）：
当坍缩从统一源创造多个粒子时发生纠缠。

*证明*：
1. 初始：单一系统处于态ψ₀
2. 坍缩事件创造两个子系统
3. 总坍缩必须守恒：𝒞(ψ₀) = 𝒞(ψ_A ⊗ ψ_B)
4. 守恒约束创造关联
5. 例子：自旋守恒
   ψ₀(自旋=0) → ψ_A(↑)ψ_B(↓) + ψ_A(↓)ψ_B(↑)
6. 任一粒子都没有确定态
7. 它们保持单一坍缩的不同方面 ∎

纠缠 = 共享坍缩遗产！

## 14.2 贝尔定理推导

**定理 14.2**（贝尔不等式违反）：
共享坍缩违反局域实在论约束。

*证明*：
1. 考虑沿轴a、b的自旋测量
2. 共享坍缩给出关联：
   E(a,b) = -a·b = -cos(θ)
3. 局域实在论假设预存值
4. 这约束关联：
   |E(a,b) - E(a,c)| ≤ 1 + E(b,c)
5. 选择：a⊥b, b⊥c, 角度(a,c) = 45°
6. 量子：|−0 − 0| = 0 ≤ 1 + (−1/√2) ✗
7. 违反：0 > 1 − 1/√2 ≈ 0.29
8. 局域实在论失败！∎

共享坍缩超越局域约束！

## 14.3 为什么无通信？

纠缠不能传输信息。

*证明*：
1. Alice测量她的粒子：ρ_A

4. Bob看到相同统计，无论Alice的行动
5. 无信息传输
6. 关联只在比较结果时可见
7. 需要经典通信才能看到 ∎

关联而无通信！

## 14.4 量化纠缠

**例子**：

- 贝尔态：S = log 2（最大）
- 部分：0 < S < log 2

## 14.6 单配性定理

**定理 14.5**（纠缠单配性）：
与一方的最大纠缠阻止与他方的纠缠。

*证明*：
1. A与B最大纠缠：
   |ψ_AB⟩ = (|00⟩ + |11⟩)/√2
2. 约化态：ρ_A = I/2（最大混合）
3. 与C纠缠需要纯ρ_A
4. 矛盾：不能既混合又纯
5. 因此：无三方最大纠缠
6. 定量：S(A:B) + S(A:C) ≤ 2S(A) ∎

坍缩只能在两者间完全共享！
