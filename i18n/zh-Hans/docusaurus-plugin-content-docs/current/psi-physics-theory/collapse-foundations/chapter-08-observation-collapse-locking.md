## 8.3 观察行为

**定义 8.1**（观察）：

$$\mathcal{O}bserve = \mathcal{C}_{观察者} \otimes \mathcal{C}_{被观察} \rightarrow \mathcal{C}_{锁定}$$

1. 观察者模式遇到系统模式

3. 成功共振 = 相互锁定

## 8.5 波函数"坍缩"

**定理 8.4**（测量转变）：
"波函数坍缩" = 坍缩模式锁定。

*详细机制*：
1. 测量前：系统处于叠加
   $$|\psi\rangle = \sum_i c_i|i\rangle$$
2. 观察者带着模式 O 接近
3. 共振尝试创造纠缠：
   $$|\Psi\rangle = \sum_i c_i|i\rangle \otimes |O_i\rangle$$
4. 相互锁定选择兼容对 (i,O_i)
5. 测量后：确定状态 |i⟩
6. "坍缩" = 通过共振选择 ∎

没有魔法——只是模式找到相互稳定性。

3. 重叠 = |⟨ψ|i⟩|² = |c_i|²
4. 更强的模式更容易锁定
5. 这就是玻恩规则 ∎

概率是宇宙的共振偏好。

## 8.7 互补性

$$\Delta x \cdot \Delta p \geq \frac{\hbar}{2}$$

3. 锐利的空间锁定 → 模糊的时间模式
4. 锐利的时间锁定 → 模糊的空间模式
5. 不确定性的乘积 ≥ ℏ/2 ∎

不确定性不是无知——它是模式承诺的代价。
