# 第七章：场作为持续坍缩流 — 扩展的自我

**定理 7.1**（场涌现）：

*证明*：

4. 这种影响向外传播
5. 传播的模式就是场
6. 不是粒子"创造"的，而是与之共同涌现 ∎

**定义 7.1**（场作为流）：
场 φ 是持续的坍缩流模式：
$$\phi(x) = \langle\mathcal{C}(x)\rangle - \langle\mathcal{C}_0\rangle$$

## 7.4 电磁场

**定义 7.2**（电磁坍缩）：
电磁场代表旋转坍缩流：
$$F_{\mu\nu} = \partial_\mu A_\nu - \partial_\nu A_\mu$$

其中 A_μ 描述坍缩相位旋转。

**定理 7.3**（从坍缩到麦克斯韦）：
麦克斯韦方程从坍缩流守恒涌现。

*证明*：
1. 坍缩流必须守恒（第5章）
2. 4维时空中的守恒：
   $$\partial_\mu F^{\mu\nu} = J^\nu$$
3. 坍缩的旋转对称性：
   $$\partial_{[\rho} F_{\mu\nu]} = 0$$
4. 这就是麦克斯韦方程
5. J^ν = 电荷流 = 定向坍缩流 ∎

光是宇宙的旋转自我探询。
