# Chapter 18: Gravitational Lensing as ψ-Density Focusing

## The Cosmic Lens Factory

Gravitational lensing—the bending of light by massive objects—reveals itself as collapse density focusing light paths. Rather than mass bending spacetime which then bends light, collapse fields directly focus propagating waves like cosmic lenses. This reinterpretation explains lensing phenomena while predicting new effects invisible to traditional gravity theory.

## 18.1 Collapse Optical Properties

**Definition 18.1** (ψ-Refractive Index):
Collapse fields create an effective refractive index:
$$n(\vec{x}) = 1 + \frac{2\Phi_{\psi}(\vec{x})}{c^2}$$

where Φ_ψ is the collapse potential.

Light follows paths minimizing optical path length through this medium.

## 18.2 Lens Equation Reformulation

The ψ-lens equation becomes:

$$\vec{\beta} = \vec{\theta} - \vec{\alpha}_{\psi}(\vec{\theta})$$

where deflection angle:
$$\vec{\alpha}_{\psi} = \frac{4G}{c^2} \int \frac{\psi(\vec{\xi})(\vec{\theta} - \vec{\xi})}{|\vec{\theta} - \vec{\xi}|^2} d^2\xi$$

β = source position, θ = image position.

## 18.3 Focusing Regimes

**Theorem 18.1** (Critical Collapse Density):
Strong lensing occurs when surface density exceeds:
$$\Sigma_{crit} = \frac{c^2}{4\pi G} \frac{D_s}{D_l D_{ls}}$$

where D represents angular diameter distances.

*Proof*:
Multiple images require ∂β/∂θ = 0 somewhere. This occurs when convergence κ = Σ/Σ_crit ≥ 1. ∎
