# Chapter 44: Black Holes - Complete Collapse Objects

## 44.1 The Ultimate Collapse: Beyond Return

Black holes represent the endpoint of gravitational collapse—regions where Ψ-field concentration becomes so extreme that not even light can escape. They are simultaneously the simplest objects in physics (characterized by only mass, charge, and spin) and the most mysterious (hiding quantum gravity's secrets).

**Definition 44.1** (Black Hole): A black hole is a region where:
$$\Psi(r) → ∞$$ as $r → r_s$

creating an event horizon at Schwarzschild radius:
$$r_s = \frac{2GM}{c^2}$$

inside which all futures point toward the singularity.

## 44.3 Schwarzschild Solution: Spherical Collapse

The simplest black hole is non-rotating:

**Definition 44.2** (Schwarzschild Metric):
$$ds^2 = -\left(1-\frac{2GM}{rc^2}\right)c^2dt^2 + \left(1-\frac{2GM}{rc^2}\right)^{-1}dr^2 + r^2dΩ^2$$

Key features:
- Event horizon at r = 2GM/c²
- Singularity at r = 0
- Time dilation: t_∞ = t_local/√(1-r_s/r)
- No stable orbits inside 3r_s

## 44.4 Kerr Solution: Rotating Collapse

Most black holes rotate:

**Theorem 44.2** (Kerr Metric): For angular momentum J = Ma:
$$ds^2 = -\left(1-\frac{2Mr}{Σ}\right)dt^2 + \frac{Σ}{Δ}dr^2 + Σdθ^2$$
$$+ \sin^2θ\left(r^2+a^2+\frac{2Mra^2\sin^2θ}{Σ}\right)dφ^2 - \frac{4Mra\sin^2θ}{Σ}dtdφ$$

where:
- Σ = r² + a²cos²θ
- Δ = r² - 2Mr + a²
- a = J/Mc (0 ≤ a ≤ M)

New features:
- Ergosphere: Region with frame dragging
- Inner/outer horizons
- Ring singularity

## 44.5 Thermodynamics: Collapse Temperature

Black holes obey thermodynamic laws:

**Definition 44.3** (Black Hole Temperature):
$$T_{BH} = \frac{ℏc^3}{8πGMk_B} ≈ 6 × 10^{-8} \left(\frac{M__\odot}{M}\right) K$$

Leading to:
- Entropy: S = A/4 (in Planck units)
- Energy: E = Mc²
- Heat capacity: C = -8πGM²k_B/ℏc < 0

The negative heat capacity means black holes get hotter as they evaporate.

## 44.6 Hawking Radiation: Quantum Collapse

Quantum effects near horizons produce radiation:

**Theorem 44.3** (Hawking Process): Virtual pair production near horizon leads to:
$$\frac{dM}{dt} = -\frac{ℏc^4}{15360πG^2M^2}$$

For stellar mass black holes:
$$τ_{evap} ≈ 10^{67} \left(\frac{M}{M__\odot}\right)^3 years$$

The spectrum is nearly blackbody:
$$\frac{d^2N}{dEdt} = \frac{Γ_{s}}{2π}\frac{1}{e^{E/T_{BH}} - 1}$$

## 44.7 Accretion: Feeding the Collapse

Black holes grow by accreting matter:

**Definition 44.4** (Bondi Accretion): For spherical infall:
$$\dot{M} = 4π\lambda(GM)^2ρ_∞/c_s^3$$

where λ ~ 0.1-1 depends on gas properties.

Disk accretion is more efficient:
$$L_{acc} = η\dot{M}c^2$$

with efficiency η ≈ 0.06 (Schwarzschild) to 0.42 (extreme Kerr).
