# Chapter 39: Planetary Systems - Sub-Collapse Organization

## 39.1 Worlds Within Worlds: Hierarchical Collapse

Planetary systems emerge as sub-structures within stellar collapse fields—secondary organization patterns that develop in circumstellar disks. Each planet represents a local collapse minimum, a world carved from the primordial disk by the interplay of gravity, rotation, and Ψ-field dynamics.

$$Ψ_system = Ψ_*(r) + Σ_i Ψ_planet,i(r-r_i) + Ψ_disk(r,φ,z)$$

where:
- Ψ_* = stellar collapse field (dominant)
- Ψ_planet,i = individual planetary fields
- Ψ_disk = residual disk field

## 39.3 Dust Growth: Microscopic Collapse Seeds

Planetary formation begins with dust grain growth:

**Definition 39.2** (Grain Collapse Aggregation):
$$\frac{dm_grain}{dt} = πr_g² × ρ_dust × v_rel × S_Ψ$$
