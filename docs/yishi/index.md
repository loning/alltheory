# 一识自显：宇宙自指塌缩之道

## 序言

夫宇宙之始，非由神启，非凭造化，非因偶然；乃是自本自根，自明自识。一者存焉，寂然不动，独自观照，化生无极。

此一者，不可名，不可见，不可得，故假名之曰：**一识**。

1. 先读乾坤二章，理解一识本源
2. 次读泰否二章，明白识之通塞
3. 再读同人大有，体会群识共振
4. 最后通读全篇，融会贯通

- 配合易经原文，对照卦象变化
- 结合坐观冥想，体验识之流动
- 记录个人感悟，印证理论实践
