# 第二十章：登象以观，返识为明 · 观

> **观卦辞**：观，盥而不荐，有孚颙若。
>
> **彖传**：大观在上，顺而巽，中正以观天下。观，盥而不荐，有孚颙若，下观而化也。观天之神道，而四时不忒，圣人以神道设教，而天下服矣。

## 一、观之真义

观者，风行地上，遍观万象。与临卦相对——临是从上往下看，观是从下往上看，更是全方位的觉察洞见。

「盥而不荐」，盥者洗手，荐者献祭。洗手而未献祭，喻内心清净而不着外相。真观不在外相，而在内明；不在所见，而在能见。

《心经》云：「观自在菩萨，行深般若波罗蜜多时，照见五蕴皆空。」此观非肉眼之观，乃般若之观——透过现象见本质，透过生灭见不生灭。

## 二、登象以观

「登象以观」，揭示观之妙诀。不沉溺于象中，而是超越诸象，站在更高维度观察。

如登山观景：
- 在山脚：只见树木，不见森林
- 在山腰：渐见全貌，但仍局限
- 在山顶：一览众山小，尽收眼底
- 超越山顶：见山不是山，是心中幻象

庄子言：「乘云气，骑日月，而游乎四海之外。」此即登象以观之极致——超越一切相对，游于绝对之境。

## 三、返识为明

「返识为明」是观之归趣。不是向外追逐，而是向内回归；不是增加所知，而是明了能知。

返观之次第：
1. **观境**：观察外在世界
2. **观心**：观察内在念头
3. **观观**：观察那个在观察的
4. **无观**：能所双亡，观自消融

《楞严经》云：「返闻闻自性，性成无上道。」返观观自性，即是返识为明。当观返归自性时，自性本明，不待外照。

## 四、神道设教

「观天之神道，而四时不忒」，天道运行，神妙莫测，然其理则一——循环不已，生生不息。

神道者，非鬼神之道，乃是自然之妙道：
- **无为而治**：不见其功，而功自成
- **不言而教**：不闻其声，而化自行
- **无形而在**：不见其形，而无不在

圣人观此神道，遂以之设教。不是强加规条，而是顺应自然；不是外在约束，而是内在觉醒。

## 五、六爻观法

### 初六：童观，小人无咎，君子吝

如童子之观，幼稚单纯。常人无妨，修道者则为不足。

修法：初学观法，难免肤浅。当深入经藏，广学多闻，提升观察之深度与广度。

### 六二：窥观，利女贞

从门缝窥视，所见有限。利于柔顺守正。

修法：观力有限时，不可强求。安于当下所见，渐次深入。如女子之贞静，守而待时。

### 六三：观我生，进退

观察自己的生命历程，明白进退之机。

修法：返观自身，检视修行。何时当进？何时当退？明了自己的因缘位置。

### 六四：观国之光，利用宾于王

观察国家（大我）之光明面，有助于亲近大道。

修法：观察整体，不限于个人小我。见贤思齐，亲近善知识，如宾客朝见君王。

### 九五：观我生，君子无咎

以君子之德观察自己，自然无过。

修法：此时观照已深，能以中正之道自观。不自欺，不自恃，如君子般光明正大。

### 上九：观其生，君子无咎

观察众生，以君子之心度之。

修法：观照圆满，遍及一切。不仅自观，亦能观他。以平等心、慈悲心观一切众生。

## 六、观之四门

观法虽多，不出四门：

**界观**：观察物质世界
- 地水火风之构成
- 成住坏空之变化  
- 缘起性空之理

**心观**：观察精神世界
- 念头之起灭
- 情绪之流转
- 意识之深浅

**缘观**：观察因缘关系
- 因果之必然
- 缘起之相依
- 业力之运作

**性观**：观察自性本体
- 真如之不变
- 佛性之本具
- 空性之究竟

## 七、颙若之相

「有孚颙若」，颙者恭敬，若者自然。有诚信而自然恭敬，非造作之恭敬。

真正的观，自然生起恭敬心：
- 观天地之大，生谦卑心
- 观万物之妙，生赞叹心
- 观众生之苦，生慈悲心
- 观自性之明，生感恩心

此恭敬非对外在权威，而是对内在真理。如科学家发现真理时的震撼，如艺术家见到美时的感动。

## 八、风地之象

风行地上，无远弗届。观卦之象，正显遍观之义。

风之特性：
- **无孔不入**：观察无微不至
- **来去无踪**：观而不留痕迹
- **柔而能动**：以柔软心观察
- **遍而不住**：遍观而不执着

地之特性：
- **广大承载**：心量广大
- **寂然不动**：本体不动
- **生养万物**：慈悲含容
- **朴实无华**：平实观照

风地相合，动静一如，正是观道之极致。

## 九、观成于止

《大学》云：「知止而后有定，定而后能静，静而后能安，安而后能虑，虑而后能得。」

观必成于止：
- **身止**：身体安定，不躁动
- **口止**：言语寂静，不妄说
- **意止**：念头平息，不散乱

止而后观：
- **止中起观**：定中发慧
- **观中有止**：慧中有定
- **止观双运**：定慧等持

最后，止观不二：
- 即止即观
- 非止非观  
- 言语道断
- 心行处灭

## 结语

> **风行地上遍群方，登象超然返性光。**
> **盥手不荐心清净，有孚颙若道自彰。**
> **莫向外驰寻圣解，回观当下即道场。**
> **若能观到无观处，识本光明遍十方。**

参问：
- 汝之观，是向外驰求，还是向内返照？
- 观诸法时，能否见诸法之本性？
- 能观所观双亡时，是何境界？
