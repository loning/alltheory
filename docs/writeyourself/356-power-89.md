## Sophie Germain 89

```python
def sophie_89():
    """89 is a Sophie Germain prime"""
    
    # 89 is prime
    # 2×89+1 = 179
    # 179 is prime!
    # Sophie Germain
    
    # 89是素数
    # 2×89+1 = 179
    # 179是素数！
    # 索菲热尔曼
    
    def is_prime(n):
        if n < 2: return False
        for i in range(2, int(n**0.5) + 1):
            if n % i == 0: return False
        return True
    
    sophie = 89
    safe = 2 * sophie + 1
    
    return is_prime(sophie) and is_prime(safe)
```
