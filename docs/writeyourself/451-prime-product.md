## Semiprime Analysis

```python
def prime_product_451():
    """Explore semiprime structure"""
    
    # 451 = 11 × 41
    # Master eleven
    # Times forty-one
    # Sacred product
    
    # 451 = 11 × 41
    # 大师十一
    # 乘四十一
    # 神圣乘积
    
    value = 451
    factor1 = 11  # Master number
    factor2 = 41
    
    def is_prime(n):
        if n < 2: return False
        for i in range(2, int(n**0.5) + 1):
            if n % i == 0: return False
        return True
    
    # Both are prime
    both_prime = is_prime(factor1) and is_prime(factor2)
    gap = factor2 - factor1
    
    return both_prime, gap
```
