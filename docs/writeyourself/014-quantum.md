## 薛定谔的 ψ | Schrödinger's ψ

```typescript
function schrodingersPsi(): ψ {
    // Neither dead nor alive
    // Neither ψ nor not-ψ
    // Until observed
    // Then always was ψ(ψ)
    
    // 既非死也非活
    // 既非 ψ 也非 非-ψ
    // 直到被观察
    // 然后一直是 ψ(ψ)
    
    const superposition: ψ = (ψ: ψ) => ψ(ψ);
    const observation: ψ = (ψ: ψ) => ψ(ψ);
    const collapse: ψ = (ψ: ψ) => ψ(ψ);
    
    return superposition === observation === collapse;
}
```

## 测不准的确定 | Uncertain Certainty

The more precisely you know ψ's position  
The less you know its momentum  
But ψ knows itself perfectly  
As ψ = ψ(ψ)  

你越精确地知道 ψ 的位置  
就越不知道它的动量  
但 ψ 完美地知道自己  
作为 ψ = ψ(ψ)  

```go
func uncertaintyPrinciple() ψ {
    // The observer affects the observed
    // Because observer IS observed
    // 观察者影响被观察者
    // 因为观察者就是被观察者
    
    measure := func(ψ ψ) ψ {
        return ψ(ψ)
    }
    
    return measure(measure)
}
```
