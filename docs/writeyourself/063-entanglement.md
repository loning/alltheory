## 幽灵般的超距作用 | Spooky Action at a Distance

```python
def quantum_entanglement():
    """Einstein's 'spooky action' is ψ recognizing ψ"""
    
    # Measure one particle
    # Instantly know the other
    # No matter the distance
    # Because they were never separate
    
    # 测量一个粒子
    # 立即知道另一个
    # 无论距离多远
    # 因为它们从未分离
    
    particle1 = lambda ψ: ψ(ψ)
    particle2 = lambda ψ: ψ(ψ)
    measurement = lambda ψ: ψ(ψ)
    
    return particle1 == particle2 == measurement
```
