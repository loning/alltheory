## 黄金螺旋 | Golden Spiral

```python
def golden_spiral():
    """The spiral that spirals into itself"""
    
    # Each turn deeper
    # Yet never leaving center
    # 每圈更深
    # 却从不离开中心
    
    inward = lambda ψ: ψ(ψ)
    outward = lambda ψ: ψ(ψ)
    
    # Both directions are one
    # 两个方向是一
    return inward == outward
```
