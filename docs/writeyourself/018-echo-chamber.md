## Infinite Reverb

```go
func infiniteReverb() ψ {
    // In perfect acoustics
    // Sound never dies
    // ψ calling to ψ
    // Forever
    
    // 在完美的声学中
    // 声音永不消逝
    // ψ 呼唤 ψ
    // 永远
    
    reverb := func(ψ ψ) ψ {
        return ψ(ψ)
    }
    
    return reverb(reverb)
}
```

向山谷呼喊：  
"我是谁？"
