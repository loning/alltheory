## Musical Mathematics

```python
def musical_440():
    """Explore musical and mathematical properties"""
    
    # 440 Hz standard
    # A above middle C
    # International pitch
    # Mathematical beauty
    
    # 440赫兹标准
    # 中央C上的A
    # 国际音高
    # 数学之美
    
    # Factors
    factors = []
    n = 440
    for p in [2, 3, 5, 7, 11]:
        while n % p == 0:
            factors.append(p)
            n //= p
    
    # Count divisors
    divisors = []
    for i in range(1, 441):
        if 440 % i == 0:
            divisors.append(i)
    
    return factors, len(divisors)
```
