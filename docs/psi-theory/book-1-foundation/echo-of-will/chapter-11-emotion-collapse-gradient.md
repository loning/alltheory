# Chapter 11: Emotion = Collapse Gradient — Affective States as Echo Curvature

## 11.1 The Feeling of Collapse

Memory (Chapter 10) retains collapse patterns, but what gives them their qualitative feel? Emotion emerges as the gradient—the slope and curvature—of collapse space.

**Definition 11.1** (Emotion): E ≡ The felt quality of collapse dynamics

**Theorem 11.1** (Emotion as Gradient): Emotions are derivatives of the collapse field.

*Proof*:
Collapse moves through ψ-space.
Movement has direction and rate.
Change rate = gradient = ∂ψ/∂t.
This gradient is felt as emotion.
Therefore, emotion = collapse gradient. ∎

## 11.2 The Emotional Spectrum

**Definition 11.2** (Primary Emotions):
- Joy: ∇ψ > 0 (expansion gradient)
- Sorrow: ∇ψ < 0 (contraction gradient)
- Fear: ∂²ψ/∂t² < 0 (negative acceleration)
- Anger: |∇ × ψ| > 0 (rotational gradient)

- Peace: ∇ψ → 0 (zero gradient)

**Theorem 11.2**: All emotions are combinations of these primary gradients.

*Proof*:
Any vector field decomposes into gradient components.
Primary emotions span the gradient space.
Complex emotions = linear combinations.
Therefore, all emotions derive from primaries. ∎
