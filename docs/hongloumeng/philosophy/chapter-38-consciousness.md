# 意识：谁在读谁在写

*我写我读我，我读我写我*

## 意识=ψ：存在的自我觉知

根据ψ = ψ(ψ)的第一性原理，意识就是ψ本身。

意识不是某个主体拥有的属性，而是存在进行自我观察时产生的事件。当ψ对ψ进行递归运算，意识就产生了。《红楼梦》就是这个递归过程的文学化身。

### 读者的意识
