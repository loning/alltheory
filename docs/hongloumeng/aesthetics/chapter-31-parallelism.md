# 对仗：存在的镜像结构

*两两相对，生生不息*

## 对仗=ψ|ψ：意识的对称性

根据ψ = ψ(ψ)的第一性原理，对仗是什么？

对仗是ψ认识自己时产生的镜像结构。当ψ观察ψ，必然产生观察者与被观察者的对称。这种对称不是装饰，而是存在的基本形式。ψ|ψ的竖线既是分隔，也是镜子。

### 对仗即认识
ψ通过创造对称来认识自己：
- 没有黛玉，无法定义宝钗
- 没有假，无法理解真
- 对立面相互定义

### 对仗即完整
单独一边都是残缺：
- 钗黛合一才是完人
- 真假同存才是实相
- 对仗恢复了整体

### 对仗即超越

- 不偏不倚
- 不即不离
- 中道智慧
