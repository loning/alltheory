## 一、《红楼梦》版本说明

### 主要版本系统

1. **脂评本系统**
   - 甲戌本（1754年）
   - 己卯本（1759年）
   - 庚辰本（1760年）
   - 蒙古王府本
   - 戚序本
   - 杨藏本
   - 特点：保留脂砚斋等人批语

2. **程高本系统**
   - 程甲本（1791年）
   - 程乙本（1792年）
   - 特点：120回完整版

3. **现代整理本**
   - 人民文学出版社版
   - 上海古籍出版社版
   - 特点：综合各版本优点

### 本书采用版本

本书分析基于120回通行本，理由：
- 体现ψ的完整周期
- 包含语言崩坏的必然过程
- 前80回与后40回形成完整的兴衰曲线

## 三、术语表

### A-G

**Awakening（觉醒）**
- 中文：觉醒
- 含义：ψ完全认识自己的状态
- 例子：宝玉出家

**Collapse（坍缩）**
- 中文：坍缩
- 含义：从可能到现实的转化
- 例子：石头变宝玉

**Dream（梦）**
- 中文：梦
- 含义：ψ的游戏状态
- 例子：太虚幻境

**Fractal（分形）**
- 中文：分形
- 含义：部分包含整体信息
- 例子：每一回都是全书缩影

### H-P

**Holographic（全息）**
- 中文：全息
- 含义：整体存在于每个部分
- 例子：第5回包含全书

**Loop（循环）**
- 中文：循环
- 含义：结束即开始
- 例子：石头→宝玉→石头

**Mirror（镜像）**
- 中文：镜像
- 含义：自己映照自己
- 例子：宝黛关系

**Psi（ψ）**
- 中文：普西/意识
- 含义：一切的本源
- 例子：整个红楼世界

### R-Z

**Recursion（递归）**
- 中文：递归
- 含义：自己包含自己
- 例子：石头记录石头的故事

**Self-reference（自指）**
- 中文：自指
- 含义：指向自己的指向
- 例子："这句话是假的"

**Unfold（展开）**
- 中文：展开
- 含义：从一到多的过程
- 例子：ψ分化为众多人物

**Void（空）**
- 中文：空
- 含义：ψ的原初状态
- 例子：太虚幻境

## 七、技术说明

### 符号使用

- **ψ**：希腊字母psi，Unicode: U+03C8
- **上标**：ψ⁰ ψ¹ ψ² ψ³ ψⁿ
- **下标**：ψ₀ ψ₁ ψ₂ ψ₃ ψₙ
- **特殊**：ψ∞ ψ⁻¹

### 公式表示

- 基本公式：ψ = ψ(ψ)
- 展开形式：ψ → ψ(ψ) → ψ(ψ(ψ)) → ...
- 简化表示：ψⁿ = ψ的n次递归
